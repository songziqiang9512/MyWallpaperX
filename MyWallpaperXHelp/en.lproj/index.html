MyWallpaperX runs moving wallpaper behind everything you do — a looping video, a living web page, or a Metal-rendered Scene. This guide covers what the app actually does, where each control lives, and what it will refuse to do.

Getting started

What the app is, what it needs, and where everything lives.

MyWallpaperX keeps a moving desktop behind your windows. It is not a screensaver and not a slideshow: it runs one wallpaper at a time, on one or more displays, and steps out of the way when you ask it to. There are three engines — video, web, and Scene — plus still images, which the app hands to macOS and does not animate itself.

What it needs

  • macOS 26 or later. The app is built against macOS 26 and does not run on older releases.
  • Accessibility is not required. The app reads system audio only if you enable the spectrum, and asks for permission at that moment.
  • A Steam account only if you browse the Workshop. Everything else works without signing in.

Your first wallpaper

  1. Open My Videos, My Images, or Workshop in the sidebar. Pixabay, Wallhaven, and Pixiv are under Browse.
  2. Click a card to play it as your wallpaper. Hovering shows the item's size and source.
  3. Set a different click action in Settings › Playback Modes if you would rather open details first.
Where things go

Imports and downloads land in My Downloads. Anything you have played appears in Recently Used. Playlists you create live under All Playlists; favourites appear under Favorite. Files are copied into the app's own library folder — moving or deleting the original file afterwards does not break your wallpaper.

The menu bar

The menu bar icon opens a panel with the current wallpaper, play or pause, previous and next, and a shortcut to Settings. Closing the main window leaves the wallpaper playing; the app keeps running until you quit it from the menu bar or press ⌘Q.

Video wallpapers

Local files, downloaded clips, and anything with a picture track.

The video engine loops a single file with audio, in a window that follows the desktop. It accepts MP4, MOV, and M4V. Codecs the system can play will play; unsupported audio or video tracks fail at load and leave the previous wallpaper running.

Adding files

Use File › Import or drop files onto the window. Imported files are copied into the library, so the app keeps playing even if you move the originals. Downloads from Pixabay, Wallhaven, and the Workshop arrive the same way.

Power

A looping 4K video decodes continuously and keeps the GPU awake. If a laptop gets warm on battery, enable Pause When on Battery in Settings › System Behavior, or use a smaller file. The spectrum adds a small cost on top: it captures system audio and drives a bar display every frame.

Web wallpapers

A page, rendered behind your work, that can move and make sound.

Web wallpapers run in a separate host process, so a page that hangs or crashes does not take the app with it. A wallpaper can be a remote URL or a local HTML bundle; the host follows the desktop and can play audio if the page does.

Adding a page

  1. Choose File › Import and pick an HTML file or a folder containing index.html.
  2. For a remote page, paste its URL in the same import sheet.
  3. The page loads once and keeps running while it is the active wallpaper.
Pages that need a login

A remote page runs without your browser cookies or extensions. If a site needs a signed-in session, it will not be signed in here. Use a local page for anything that depends on your account.

Failure is quiet

If the host cannot start, the page fails to load, or the page is closed, the app keeps the previous wallpaper in place and reports the reason rather than showing a blank desktop. Reloading the wallpaper retries the same host.

Song info

Web and Scene wallpapers can show the track that is currently playing, with artwork, if the wallpaper supports it. The app reads Apple Music when you turn Wallpaper Song Info on; macOS asks for Automation permission the first time, and the setting stays off until permission is granted.

Scene wallpapers

Wallpaper Engine projects, rendered by Metal, with their properties editable here.

Scene wallpapers are Wallpaper Engine projects: a folder with project.json and the assets it references, packaged as a .pkg or imported from the Workshop. The app renders them with Metal rather than running Wallpaper Engine.

Properties

Select a Scene wallpaper and open Configure to edit the properties the project exposes — colours, sliders, combos, checkboxes, and text. Edits apply on the next frame; you do not have to reload the wallpaper. A property that is out of its declared range is rejected with the range in the message.

SettingEffectWhen to change it
Scene HDRRenders into an extended-range target when the project supports it.Only on an HDR display, and only if the project was authored for it. Power draw rises noticeably.
Scene Frame Rate CapLimits Scene rendering to 30 or 60 fps.Leave on 30 for everyday use; raise it for fast scenes on a desktop that is plugged in.
Multiple DisplaysShows Scene, Web, and Video wallpapers on every display.When you want one wallpaper across the desk instead of a still image on the secondary screen.
If a Scene fails

A project that cannot be parsed, references a missing asset, or uses a feature the renderer does not implement leaves the previous wallpaper playing. The message names the project and the step that failed — parsing, preparing resources, or the first frame.

Workshop and Steam

Browsing, subscribing, and downloading Wallpaper Engine items with a Steam account.

The Workshop browser talks to Steam through a helper that ships inside the app. You sign in once; the app keeps the session and shows your owned and subscribed items alongside the public catalogue.

Signing in

  1. Open Workshop in the sidebar.
  2. Sign in with the QR code — scan it in the Steam mobile app — or with your password and a Steam Guard code.
  3. If the session expires, the browser asks you to sign in again instead of showing an empty list.

Browsing and downloading

Search and filters apply to the catalogue as you type. Opening an item shows its screenshots, size, and required engine. Subscribing adds it to your downloads; the download queue runs in the background and can be cancelled per item. Downloaded items appear under My Downloads and can be played without Steam running.

Accounts

A saved sign-in is tied to the Steam account that created it. If the helper reports a different account, the app asks you to sign in again rather than mixing libraries.

When Steam is not there

If the helper cannot start or Steam is unreachable, browsing and downloads fail with a message that names the step. Everything already downloaded keeps working — Workshop wallpapers are local files once they land.

Pixabay, Wallhaven, Pixiv

Three online sources, each with its own key or sign-in.

SourceNeedsWhat it gives you
PixabayAn API key from your Pixabay accountFree videos and photos, searchable; videos download straight into My Downloads.
WallhavenAn API key; required for NSFW contentWallpapers and filters, including purity and category. Without a key you browse in anonymous mode.
PixivYour Pixiv sign-inRankings, search, and artist pages. Downloads keep the file in your library.

Keys stay on your Mac

API keys are stored in the app's settings and sent only to the service they belong to. Settings › Playback Modes shows whether a key is set without printing it. Removing a key stops the source from loading until you add another.

Rate limits

Each service limits how often you can ask. The app surfaces the service's own message when a request is throttled instead of retrying in a loop. If a search stops returning results, wait a moment and try again.

Your library

One place for everything you have imported, downloaded, or played.

The sidebar groups your content by where it came from and what you have done with it. Cards show a thumbnail; thumbnails are generated in the background, so a freshly imported file may show a placeholder for a few seconds.

Working with many items

  • Search filters the current page as you type; Edit › Search focuses the field.
  • Select All and Toggle Multiple Selection let you act on several items; Delete Selected removes them from the library.
  • Views, sorting, and thumbnail size live in View; they apply to the page you are on.
  • A playlist is created with File › New Playlist… and filled by dragging items onto it.
Deleting

Removing an item from the library deletes the app's copy, not the file you originally imported. If the item is currently playing, the wallpaper stops and the desktop returns to the system picture.

Playback and power

How the wallpaper advances, and how to stop it from costing more than it should.

Advancing

Play in Order and Shuffle decide what plays next within a playlist. Auto Switch moves to the next wallpaper on an interval you set in minutes; with it off, the current wallpaper stays until you choose another.

Pausing

Four rules can pause the wallpaper without stopping it. Each is independent; any one of them pauses playback while its condition holds.

RulePauses whenNotes
Pause When Another App Is FocusedAnother app is in front.Finder on the desktop and MyWallpaperX itself are excluded.
Pause When Another App Is Full ScreenAn app covers the main desktop in full screen.Useful for games and video calls.
Pause When on BatteryThe Mac is running on battery.The simplest way to stop a laptop from warming up.
Pause When IdleYou have not touched the Mac for the idle time you set.Set between 1 minute and an hour.
HDR and frame rate

Scene HDR and a 60 fps cap both raise power draw. The app warns about HDR when you turn it on; it does not turn itself off later. If the machine gets hot, drop the cap to 30 first, then disable HDR.

At login

Launch at Login starts the app with your session. Resume Playback at Launch restores the last video, web, or Scene wallpaper; with it off, no wallpaper plays at launch and the system picture stays. Still images are handled by macOS and are not affected by either switch.

Displays and system

Multiple screens, the system picture, the lock screen, and the keyboard.

Displays

Multiple Displays shows the wallpaper on every display. With it off, the main display plays and the others keep the system picture. Each display keeps its own window, so moving a window between screens does not restart playback.

System wallpaper sync

Sync System Wallpaper updates the macOS desktop picture whenever the wallpaper changes: a still frame for video, and a frame captured after the launch transition for web and Scene. This keeps Mission Control, spaces, and the login screen in step with what you are looking at. Static image wallpapers are always applied directly, with or without this setting.

The screen saver

The app ships a system screen saver extension that plays local videos muted on loop. Enable it in System Settings › Screen Saver, pick MyWallpaperX, then choose the video. The screen saver reads its own copy of the file, so deleting the wallpaper from the library does not break it — the app keeps the screen saver copy and tells you where it is if you remove it.

Keyboard

Playback Shortcuts binds F1–F12 to four actions: previous, next, play or pause, and mute. Each key can hold one action. Because these are global shortcuts, the function keys stop reaching other apps while they are bound.

Permissions

The app asks for Automation access the first time it reads Apple Music for song info, and for audio capture the first time you enable the spectrum. If you deny either, turn the feature off and back on after granting access in System Settings › Privacy & Security.

What the app does not do

  • It does not animate still images; those are applied through macOS.
  • It does not run Wallpaper Engine itself. Scene projects are rendered by the app's own Metal renderer, and projects built around engine-exclusive features may not render as they do in Wallpaper Engine.
  • It does not sync playlists or settings between Macs. Settings can be exported and imported as a file from the app.
