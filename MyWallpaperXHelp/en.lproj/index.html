Start with a wallpaper you love

GET STARTED

A local video, a web project or a real-time scene can become your desktop. Choose your content, then make playback fit your day.

  1. Find something

    Import local videos in My Videos. Browse the Workshop for Web and Scene projects.

  2. Apply it

    Select an item in its library and choose Set as Wallpaper. Workshop items must finish downloading first.

  3. Make it yours

    Adjust volume and pause playback. For Web and Scene, open Properties in the item details to see the author’s options.

Video · A moving picture

VIDEO WALLPAPERS

Landscapes, animation clips and seamless loops. A video file supplies the picture, making this the most direct way to get started.

What you can do

  • Import local files in My Videos, then organize them with Favorites, playlists and Recently Used.
  • Choose loop, sequential or random playback in settings, with automatic switching when needed.
  • Adjust playback speed and choose whether the video fits inside or fills the display.

Make it work well

  • Match the video’s proportions to your display. Fill Screen can crop the edges. Fit can leave empty borders.
  • Pick clips with a natural transition between the last and first frames for a smoother loop.
  • The codec inside an MP4 or MOV must also be supported by macOS. Try the file in a system video player if it will not play.

In Settings › Wallpaper Quality, Video Quality shows Original Video. Existing videos play at the quality of the stored file. When a new Pixabay download has several available sizes, choose one before downloading. The highest available size is selected initially. Playback uses the downloaded file.

Playback settings, rather than author propertiesVideos use the app’s volume, speed and playback mode settings. They do not have the author-defined property panels found in Web and Scene projects. Video Fill Mode applies to Video wallpapers.

Web · A desktop with a live view

WEB WALLPAPERS

Clocks, information displays, web animations and interactive layouts. Each project combines a web page with its resources; the author decides what it does.

What you can do

  • Filter Workshop content by Web, download a project, then play it from My Downloads.
  • Open Properties in the item details to change the colors, text, switches and other options the author exposes.
  • Supported projects can respond to the pointer or audio, when the author has included those behaviors.

Useful habits

  • Start with the default properties, then change one setting at a time.
  • Weather, remote images and other online content may need a connection, even after the project has downloaded.
  • For a blank or incomplete page, check download tasks and any failure or missing-dependency message in the list. Keep the item link and symptoms when reporting a problem.

In Settings › Wallpaper Quality, Web Frame Rate Suggestion can match the display up to 60 FPS or follow the animation frame rate you set. It affects a Web wallpaper only if the author’s code uses the suggestion.

Keep the whole project togetherA Web wallpaper is usually more than one HTML file. Do not move individual pages, images or scripts out of its folder. Presets that depend on another project need that base content too. Compatibility varies between projects.

Scene · A world built in real time

REAL-TIME SCENES

Layers, materials and animation are composed as the wallpaper runs. Supported projects can include depth, particles, dynamic text and reactive effects instead of a prerecorded video.

What you can do

  • Filter Workshop content by Scene, download an item and apply it to the desktop.
  • Use Properties to change author-provided colors, switches, values, text or image options.
  • Control playback, pause and volume through the shared controls, with energy-saving policies when needed.

Useful habits

  • Use Settings › Wallpaper Quality to adjust Scene quality and frame rate.
  • Try the default appearance before adjusting effects. Performance also depends on the complexity of the project.
  • For missing layers or unexpected effects, compare the default properties and keep the item link, screenshot and symptoms when reporting the issue.

Scene wallpaper quality

For changes that require a reload, choose Reapply Current Scene in Wallpaper Quality. The scene starts again with your saved settings and stays paused if it was paused. The marker clears once a scene prepared with those options takes over playback.

Scene Quality Preset and Animation Frame Rate. Low, Medium, High and Ultra set the Scene quality options and request 10, 15, 25 and 30 FPS respectively. You can enter any whole number from 10 to 120 FPS. A combination that differs from every preset shows as Custom. Restore Default Quality returns the request to 60 FPS. Display refresh rates and scene workload can limit presentation. Displays with different refresh rates share a cap of 60 FPS or less.

Scene Anti-Aliasing. Choose None, MSAA ×2 or MSAA ×4. Reapply the wallpaper to use the selected mode on supported devices in scenes with compatible 3D models. Compatible 2D layers can share the same mode. Purely 2D scenes and other unsupported combinations use single-sample rendering.

Scene Post-Processing. Disabled turns off scene-wide bloom. Enabled keeps standard bloom. Ultra preserves the wallpaper’s HDR effects and displays them in SDR. With at least one HDR-capable display connected, choose Ultra (Display HDR) for brighter highlights. It requires HDR in the wallpaper, and brightness depends on each screen’s current headroom. Displays that cannot use HDR continue to show SDR. You can switch between the two Ultra modes immediately. Other effect changes may require reapplying the wallpaper. If no display supports HDR, a saved choice is shown as “Ultra (Display HDR Unavailable)” and the display output uses SDR.

Textures, lighting and reflections. Texture Resolution offers Automatic, High Quality and High Performance for textures with suitable sizes. Scene Shadows affects supported shadows in the wallpaper. Volumetric Lighting offers Disabled, High and Ultra, with High and Ultra adjusting the precision of point-light volumes. Turning off Scene Reflections removes optional real-time reflections. Explicit environment effects authored in the wallpaper may remain.

Compatibility is project-specificScene compatibility is still being developed. A completed download does not guarantee every effect, script or interaction, or an exact match with Wallpaper Engine. An absent property may simply mean the author did not expose it.

Workshop & downloads

DISCOVER & MANAGE

Use your Steam account to browse projects, manage subscriptions and download wallpapers. Video, Web and Scene share this workflow.

Search & filter→Sign in when prompted→Download→Play from My Downloads

Find the right project

  • Open the Steam account control in the toolbar and follow the QR or account verification prompts.
  • Choose a content type before searching a theme. My Subscriptions shows the account’s subscribed items.
  • Open an item’s details to learn more or explore its author’s work.

Understand the queue

  • The toolbar’s download button shows queued tasks, progress and failure messages.
  • Failed items have a Retry button. Address any connection, sign-in or storage issue before retrying.
  • Clear All removes completed, failed and cancelled history. It leaves active tasks running and keeps downloaded files.
Removal, source-file deletion and subscriptions are separateRemoving an item from My Downloads keeps its disk files and other playlists by default. Only Delete source files from disk deletes files, which cannot be undone. Unsubscribing keeps local files; Clear All in the download panel only clears task history.

A place for every collection

YOUR LIBRARIES

My Videos / My Images

Import and manage local videos and images separately. Drag a wallpaper card to a playlist in the sidebar to add it quickly.

My Downloads

Manage downloaded content from Workshop, Pixabay and other online sources together. Browse to discover projects; use the library to play and organize them.

All Playlists

The first card creates a playlist. Mix images, videos, Web and Scene wallpapers; right-click a playlist to edit its name, cover and description.

Favorite / Recently Used

Favorite collects heart-marked local and downloaded wallpapers. Recently Used keeps the most recent successful plays. Download online results before adding them.

Removal affects the relationship on the current pageIn Favorite it clears the heart; in Recently Used it removes the playback record; in a custom playlist it removes that membership. Source files and other playlists are kept by default. File → Import accepts local videos or images, not Web or Scene projects.

Playback, sound & energy

SHARED CONTROLS

Video, Web and Scene share play/pause, volume and mute, along with these four energy-saving policies. Set them once for all three engines.

Pause when inactiveAfter the selected period without activity. Adjust the timeout below the switch.

Resuming playback

Playback stays paused while any enabled condition is still true. It can resume automatically once those conditions clear. A wallpaper you paused manually still needs to be resumed manually.

Sound and audio response

Volume controls the wallpaper’s own sound; it cannot add an audio track to a silent project. System-audio reactions also require a compatible wallpaper, the relevant setting and macOS permissions.

Start with a simple energy-saving setupIf you often work full screen, enable full-screen pause first. On a laptop, add battery pause as needed. Lower the animation frame rate to further reduce Scene workload.

System & screen saver

Beyond the desktop

The wallpaper does not live alone. These settings connect it to extra displays, the macOS desktop picture, the lock screen and startup.

Multiple displays

Multiple Displays in Display Settings shows the wallpaper on every display. With it off, the main display plays and the others keep the system picture.

System wallpaper sync

Sync System Wallpaper updates the macOS desktop picture whenever the wallpaper changes: a still frame for video, and one frame captured after the launch transition for Web and Scene. Mission Control, spaces and the login screen then match what you see. Static images are always applied directly.

Screen saver

The app ships a system screen saver extension. Enable MyWallpaperX under System Settings › Screen Saver and pick a local video; it loops muted. The screen saver keeps its own copy of the file, so removing a wallpaper from the library does not break it — the app keeps that copy and tells you where it is when you delete the item.

At login

Launch at Login starts the app with your session. Resume Playback at Launch restores the last video, Web or Scene wallpaper; with it off, nothing plays at launch and the system picture stays. Static images are handled by macOS and are not affected by either switch.

Appearance and click

App Theme follows the system appearance or pins light or dark. Card Click Action decides whether clicking a card plays it immediately or opens its details first; the return key and the context menu keep their own actions.

Video fill mode

Video Fill Mode offers Fit and Fill Screen. Fit shows the entire frame and may leave borders. Fill Screen covers the display and may crop the edges.

Audio spectrum

The spectrum draws bars from system audio at the bottom of the desktop. It applies to Video wallpapers only and needs audio-capture permission the first time. Bar count, colour, X and Y position and peak caps are adjustable; the feature adds a small per-frame cost.

Song info

Wallpaper Song Info shows the current track and artwork on supported Scene and Web wallpapers. macOS asks for Automation access to Apple Music the first time; until you allow it, the setting stays off. If you denied it, re-enable it in Privacy & Security › Automation and turn the switch back on.

Sign-in, one prompt at a time

Steam sign-in

The Workshop talks to Steam through the service that ships inside the app. Sign in with the QR code or with your account name and password; either way Steam may ask for a second confirmation before the session becomes usable.

Remembering a sign-inEnable Remember me to keep the session in your keychain, so the next launch restores it without a prompt. Without it you sign in again next time — that is not a failure. A message saying the session could not be saved is a real save failure. Keep passwords, codes, QR images and session tokens out of reports.
QR code will not scan / waiting for approval

Scan with the Steam mobile app. Click the code, or press Tab to “Enlarge QR Code”, for a larger view. Refresh an unusable code and scan the new one. Switching between QR and password cancels the previous attempt.

Confirm this sign-in in the Steam mobile app

A scanned code or an accepted password can still need mobile approval. The request appears in the Steam app under the device name “MyWallpaperX SteamService”. Leave the panel open and approve there; closing it or pressing Esc cancels the attempt.

Previous verification code was rejected

Steam asks for either an authenticator code or an email code. Enter a fresh code for this attempt; old codes, typos and the wrong source are rejected. For email, the panel shows which domain the message went to.

Sign-in rejected · accessDenied

Steam refused the credentials or the account’s access. Use the account name and password you log in with, not the profile display name. A wrong password and an account restriction both surface here; check the account in the official Steam client.

authExpired / saved sign-in rejected

The saved session expired or was revoked. Sign in again from the account menu with the intended account. A restore message separates a network failure from an expired session; a network failure keeps the saved sign-in and lets you retry.

Network timeout

Authentication did not finish in time. Connectivity, a proxy, Steam availability or a delayed mobile approval can be involved; a timeout alone does not prove a wrong password. Check the approval state and your connection, then retry.

rateLimited

Steam is limiting requests. Wait before retrying instead of refreshing codes or resubmitting credentials in a loop.

Signed in, but the session could not be saved

The session works now, but saving it to the keychain failed, so you may be asked again next time. This differs from leaving Remember me off. If it repeats, note the message and app version; do not start by deleting your keychain.

Steam service unavailable / incompatible / connection lost

The in-app Steam service did not start, exited, or speaks a different protocol version. Update or reinstall the complete app rather than mixing components. For a lost connection, restart and retry; if it persists, report the running version.

Browsing without signing in

Public Workshop pages and search can be read before you sign in. Downloading, subscriptions and My Subscriptions require a completed sign-in.

Make sense of a failed download

Causes & next steps

Open Download tasks and identify the failing stage: manifest lookup, CDN authorization, chunk transfer or saving local files. The same error number can call for different checks at different stages.

The downloader runs on SteamKit’s CDN client. A manifest may not exceed 8 GiB or 200,000 files; manifest and chunk transfers get up to three attempts each, plus one re-authorisation replay after a 403. A task that keeps failing at the same stage is not fixed by retrying harder.

A message may look like this · format exampleManifest download failed (HTTP 503, node <server>, attempted <count> times). Check your network and proxy settings and try again later.
HTTP 503 / 500 / 502 / 504 · network

Possible cause

A service, content node or intermediate connection is temporarily unavailable. Browsing may work while downloads fail; 503 alone does not identify an app-version or SteamKit defect.

What to do next

Retry later. Check whether your proxy covers the app’s download connections, or compare on another network. If multiple items fail, keep the node, time and full message.

HTTP 401 · authExpired

Possible cause

Download authorization or the sign-in session is no longer valid.

What to do next

Sign in again from the account menu, then retry the failed task.

HTTP 403 · accessDenied / missing CDN authorization

Possible cause

Access was denied. Content permissions, CDN authorization or a proxy may be involved; it does not always mean a wrong password.

What to do next

Check content access, networking and proxy settings. Sign in again and retry. A staging access-denied message instead points to local folder permissions.

HTTP 429 · rateLimited

Possible cause

Steam has limited the request rate.

What to do next

Wait before retrying and avoid repeatedly creating tasks. The app already makes a bounded number of retries for some temporary failures.

HTTP 404 · unsupportedContent / item has no content manifest

Possible cause

The node lacks the content, or the item has no downloadable manifest. Updated, inaccessible or non-Wallpaper Engine content can also be unavailable.

What to do next

Reopen the item and verify the link and access. Repeated downloads cannot fix a deleted, unsupported or empty item.

diskFull · Insufficient disk space

Possible cause

The staging or destination disk does not have enough space.

What to do next

Free space on the relevant disk and retry the original task. If the message says partial data was retained, keep it for retry. Allow working space beyond the advertised archive size.

integrity · Validation failed / staging identity changed

Possible cause

Content checks, file lengths or directory identity no longer agree; moving or editing staging data can cause this. The app stops the unsafe save.

What to do next

Stop external changes to the affected folders, then retry. If repeated, report the full message and item ID. Do not edit validation data to bypass checks.

manifest requires a nonempty root project.json / manifest path…

Possible cause

Required content is missing, or manifest paths or sizes fail safety checks. A network retry alone may not resolve it.

What to do next

Verify the item is a complete Wallpaper Engine project. Report the exact error instead of assembling a folder and treating it as a completed download.

Service timeout / connection lost / helperUnavailable / protocolMismatch

Possible cause

The helper may not have started, may have exited, may be incompatible, or may not have completed a request. These messages alone do not establish a Steam outage.

What to do next

Restart for a lost connection. Update or reinstall the complete app for unavailable or incompatible components. Mention any other installed app versions when reporting.

Download stopped but staging cleanup failed

Possible cause

The task stopped or content state was saved, but temporary-file cleanup failed. This is not a request to delete the wallpaper library.

What to do next

Check the task and downloaded content state first. Keep the message and check permissions or external file operations; report persistent failures.

Wait for Completed, even at 100%Transfer is followed by validation and saving. Queued, connecting or saving tasks may not show a continuous speed. Resolve the cause before Retry. Clear all removes finished task history while keeping active tasks and downloaded files.

If a completed Web or Scene item is missing a dependency, select Unavailable in My Downloads or open its details to inspect the required base item. This differs from an HTTP transfer failure. Reports should include app version and running location, item link/ID, time, full error, whether one or all items fail, and network/proxy use.

When something needs a check

TROUBLESHOOTING
The wallpaper stopped moving. Has the app frozen?

Check manual pause first, then the focus, full-screen, battery and inactivity policies. Scene follows these switches too; it does not require Finder or MyWallpaperX to stay focused in order to play.

Why is a Web wallpaper blank or missing some content?

Make sure the download is complete and check download tasks and any failure or missing-dependency message in the list. Weather, remote images and other services may be unavailable offline. A lone HTML file may not contain the entire project.

A Scene plays, but looks different from the Workshop preview.

Check your property changes against the author’s defaults. Some effects, scripts and interactions may not yet be fully compatible. Include the item link, app version, a screenshot and the affected part of the picture in your report.

A download failed with a 503 error. What should I do?

A 503 usually indicates that a service in the request path is temporarily unavailable, but the number alone does not identify the cause. Keep the error message, check your account state, connection and free space, then retry later. If multiple items keep failing, report the full error, time and app version.

Why is a wallpaper still present after clearing the queue?

Task history and local content are managed separately. Clear All keeps downloaded files. Remove wallpapers in My Downloads; source files remain unless Delete source files from disk is checked. Unsubscribing also keeps local files.

How do I check for updates or report an issue?

Choose Check for Updates… in the MyWallpaperX menu. About MyWallpaperX shows app information. Include the wallpaper type, steps to reproduce, item link or local file format, and the error message. Never include your Steam password or verification codes.

The screen saver plays nothing after I removed the wallpaper

The screen saver uses its own copy of the file, kept when you delete the library item. Re-select the video in System Settings › Screen Saver; if that copy was removed as well, add the item again and choose it.

The second display keeps a still picture

Enable Multiple Displays in Settings › Display Settings. With it off, only the main display plays; the others keep the macOS desktop picture, which Sync System Wallpaper may be updating.
