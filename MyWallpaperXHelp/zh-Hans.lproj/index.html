桌面，
是活的。

MyWallpaperX 在所有窗口后面播放会动的壁纸——循环的视频、活着的网页，或由 Metal 渲染的场景。这本手册只讲应用真正做过的事、每个开关在哪里，以及它会在什么情况下拒绝。

视频 MP4 · MOV · M4V 网页 HTML · URL · 声音 场景 Wallpaper Engine · Metal

需要 macOS 26 或更高 · 手册随应用离线提供

开始使用

它是什么、需要什么，以及东西都放在哪。

MyWallpaperX 在你的窗口后面维持一张会动的桌面。它不是屏保，也不是幻灯片：同一时间只播放一张壁纸，可以覆盖一块或多块显示器，并且在你要求时立刻让开。引擎有三个——视频、网页、场景——另有静态图片，这类图片交给 macOS 自己处理，应用不做动画。

需要什么

  • macOS 26 或更高。应用按 macOS 26 构建，旧系统无法运行。
  • 不需要辅助功能权限。只有开启频谱时才读取系统音频，并在那一刻请求授权。
  • Steam 账号只在浏览创意工坊时需要，其他功能不登录也能用。

设置第一张壁纸

  1. 在侧边栏打开我的视频、我的图片或创意工坊；Pixabay、Wallhaven、Pixiv 在“浏览”下面。
  2. 点一张卡片就能把它设为壁纸；悬停会显示来源和大小。
  3. 如果更习惯先看详情，可以在设置 › 播放模式里改单击行为。
文件放在哪

导入和下载的内容都进入我的下载；播放过的会出现在最近使用；自己建的列表在所有播放列表下，特别喜爱的在特别喜爱。文件会被复制进应用自己的资料库，之后移动或删除原文件不会让壁纸失效。

菜单栏

菜单栏图标会打开一个面板，里面有当前壁纸、播放/暂停、上一张/下一张，以及设置的入口。关掉主窗口不会停止壁纸，应用会一直运行，直到你从菜单栏退出或按 ⌘Q。

视频壁纸

本地文件、下载来的片段，以及一切带画面的东西。

视频引擎循环播放一个文件，带声音，窗口跟随桌面。支持 MP4、MOV、M4V。系统能解码的编码就能播放；音频或视频轨不受支持时会在加载阶段失败，并保留上一张壁纸。

添加文件

用文件 › 导入，或把文件拖到窗口里。导入的文件会被复制进资料库，所以移动原文件也不影响播放。从 Pixabay、Wallhaven 和创意工坊下载的内容也走同一条路径。

播放时可以调什么

控制位置作用
循环设置 › 播放模式播完从头再来。关闭后停在最后一帧。
音量 / 静音设置 › 播放模式统一设置所有视频壁纸的播放音量。
播放速率设置 › 播放模式开启速率调节后按倍数播放。
视频填充方式设置 › 显示设置画面如何适配屏幕：填充、适应或拉伸。
音频频谱设置 › 系统行为跟随系统音频的柱状可视化，只对视频壁纸生效。
功耗

循环播放 4K 视频意味着持续解码，GPU 不会休眠。笔记本在电池上发热时，打开设置 › 系统行为里的使用电池时暂停，或者换一个更小的文件。频谱会再叠一点开销：它采集系统音频并每帧驱动柱状显示。

网页壁纸

一个渲染在工作后面的页面，可以动，也可以出声。

网页壁纸跑在独立的宿主进程里，页面卡死或崩溃不会把应用一起带走。壁纸可以是远程地址，也可以是本地 HTML 包；宿主跟随桌面，页面有声音就能放出来。

添加一个页面

  1. 选择文件 › 导入，挑一个 HTML 文件，或包含 index.html 的文件夹。
  2. 远程页面在同一个导入面板里粘贴地址。
  3. 页面加载一次，只要它还是当前壁纸就一直运行。
需要登录的页面

远程页面拿不到你浏览器的 Cookie 和扩展。需要登录的站点在这里就是未登录状态；依赖账号的内容请改用本地页面。

失败是安静的

宿主起不来、页面加载失败或被关闭时，应用会保留上一张壁纸并说明原因，而不是留一张空桌面。重新加载壁纸会重试同一个宿主。

歌曲信息

网页和场景壁纸可以在支持时显示正在播放的曲目与封面。打开壁纸歌曲信息后应用会读取 Apple Music；macOS 第一次会询问“自动化”权限，在授权之前这个开关不会生效。

场景壁纸

Wallpaper Engine 项目，由 Metal 渲染，属性在这里直接改。

场景壁纸就是 Wallpaper Engine 项目：一个包含 project.json 和它引用的资源的文件夹，可以打包成 .pkg，也可以从创意工坊导入。应用用 Metal 渲染这些项目，而不是运行 Wallpaper Engine。

属性

选中一张场景壁纸，打开配置，就能改项目暴露出来的属性——颜色、滑块、下拉框、开关和文本。修改下一帧生效，不需要重新加载壁纸。超出声明范围的属性会被拒绝，提示里会带上允许的区间。

设置效果什么时候改
场景 HDR项目支持时渲染到扩展亮度范围。只在 HDR 显示器上，并且项目本身是为 HDR 做的。功耗会明显上升。
场景帧率上限把场景渲染限制在 30 或 60 fps。日常保持 30；插电的台式机想看高速场景时再调高。
多显示器让场景、网页和视频壁纸出现在每一块显示器上。想让整张桌子是一张壁纸，而不是副屏留一张静态图时。
场景失败时

项目解析不了、引用的资源缺失，或用到了渲染器没实现的功能时，上一张壁纸会继续播放。提示会说明是哪个项目、卡在哪一步——解析、准备资源，还是第一帧。

创意工坊与 Steam

用 Steam 账号浏览、订阅并下载 Wallpaper Engine 内容。

创意工坊浏览器通过应用内置的辅助进程与 Steam 通信。登录一次，应用会保留会话，把你的已拥有和已订阅内容与公开目录一起列出来。

登录

  1. 在侧边栏打开创意工坊。
  2. 用二维码登录——在 Steam 手机应用里扫码——或输入密码和 Steam 令牌。
  3. 会话过期时，浏览器会请你重新登录，而不是显示一个空列表。

浏览与下载

搜索和筛选随输入生效。打开一个条目会显示截图、大小和所需的引擎。订阅后进入下载队列，队列在后台运行，可以按条目取消。下载完成的条目出现在我的下载里，不启动 Steam 也能播放。

账号

保存的登录属于创建它的那个 Steam 账号。辅助进程报告的是另一个账号时，应用会请你重新登录，而不是把两个库混在一起。

Steam 不在的时候

辅助进程起不来或连不上 Steam 时，浏览和下载会失败，并提示卡在哪一步。已经下载的内容照常可用——创意工坊壁纸落到本地后就是普通文件。

Pixabay、Wallhaven、Pixiv

三个在线来源，各自的密钥或登录方式。

来源需要能拿到什么
PixabayPixabay 账号里的 API 密钥可搜索的免费视频与照片；视频直接下载进“我的下载”。
WallhavenAPI 密钥；浏览 NSFW 内容必须用密钥壁纸与筛选条件，包括纯度和分类。没有密钥时以匿名模式浏览。
Pixiv你的 Pixiv 登录排行榜、搜索和画师页面；下载后文件留在资料库。

密钥只在你本机

API 密钥保存在应用设置里，只发往它所属的服务。设置 › 播放模式只会显示密钥是否已设置，不会打印内容。删掉密钥后，该来源会停止加载，直到你重新添加。

频率限制

每个服务都限制请求频率。被限流时应用会显示服务自己的提示，而不是循环重试。搜索突然不出结果时，等一会儿再试。

你的资料库

导入、下载、播放过的东西，都在一个地方。

侧边栏按来源和你做过的事分组。卡片显示缩略图；缩略图在后台生成，所以刚导入的文件可能先显示占位图，过几秒才出现画面。

各个页面

页面放什么
我的视频资料库里所有视频壁纸。
我的图片静态图片，包括从壁纸截下来的画面。
我的下载从创意工坊或在线来源下载的全部内容。
最近使用最近播放过的壁纸，最新的在前。
创意工坊Steam 目录、你的订阅，以及你自己的条目。
所有播放列表你创建的播放列表，各自带着自己的壁纸。
特别喜爱跨来源标记为喜爱的条目。

批量处理

  • 搜索会随输入过滤当前页面；编辑 › 搜索可以直接聚焦输入框。
  • 全选和切换多选让你一次处理多个条目；删除所选把它们移出资料库。
  • 视图、排序和缩略图大小在显示菜单里，对当前页面生效。
  • 播放列表用文件 › 新建播放列表…创建，把条目拖进去即可添加。
删除

从资料库删除的是应用自己的副本，不是你最初导入的那个文件。如果删的正好在播放，壁纸会停下，桌面回到系统图片。

播放与能耗

壁纸怎么轮换，以及怎么让它别花费太多。

轮换

顺序播放和随机播放决定播放列表里的下一张。自动切换按你设定的分钟数换下一张；关掉之后，当前这张会一直留着，直到你手动选择。

暂停

四条规则可以在不停止壁纸的前提下暂停播放。它们彼此独立，任意一条成立就会暂停。

规则什么时候暂停说明
其他应用位于前台时暂停另一个应用在前面。桌面上的 Finder 和 MyWallpaperX 自己不算。
其他应用全屏时暂停有应用以全屏盖住主桌面。适合游戏和视频会议。
使用电池时暂停Mac 正在用电池。防止笔记本发热最简单的办法。
空闲时暂停你设定的时间内没有操作。可以设在 1 分钟到 1 小时之间。
HDR 与帧率

场景 HDR 和 60 fps 上限都会抬高功耗。打开 HDR 时应用会提醒一次，之后不会自动关掉。机器发热时先把上限降到 30，再考虑关掉 HDR。

开机与启动

登录时启动让应用随系统一起启动。启动时恢复播放会恢复上一次的视频、网页或场景壁纸；关掉后启动时不播放任何壁纸，桌面保留系统图片。静态图片由 macOS 处理，不受这两个开关影响。

显示器与系统

多块屏幕、系统图片、锁屏，以及键盘。

显示器

多显示器会让壁纸出现在每一块屏幕上。关掉后只有主显示器播放，其他屏幕保留系统图片。每块屏幕有各自的窗口，把窗口在屏幕之间拖动不会重启播放。

同步系统壁纸

同步系统壁纸会在壁纸变化时更新 macOS 的桌面图片：视频取一帧静态画面，网页和场景取启动过渡之后的一帧。这样调度中心、空间和登录界面看到的都是同一画面。静态图片壁纸始终直接应用，不受这个开关影响。

屏保

应用自带一个系统屏保扩展，静音循环播放本地视频。在系统设置 › 屏保里选择 MyWallpaperX，再挑视频即可。屏保读的是自己那份拷贝，所以从资料库删掉壁纸不会弄坏它——删除时应用会保留屏保用的副本，并告诉你它在哪里。

键盘

播放快捷键把 F1–F12 绑到四个动作上：上一张、下一张、播放/暂停、静音。每个键只能绑一个动作。这些是全局快捷键，绑定之后功能键不再传给其他应用。

权限

应用第一次读取 Apple Music 显示歌曲信息时会请求“自动化”权限，第一次开启频谱时会请求音频采集权限。拒绝之后想再用，需要先在系统设置 › 隐私与安全性里授权，再把功能关掉重开。

出问题时

现象可能原因怎么办
创意工坊里没有内容Steam 会话过期，或辅助进程没起来。在创意工坊页面重新登录；如果提示辅助进程缺失，重装应用。
网页壁纸是空白的页面加载失败，或需要登录。重新加载壁纸；需要登录的站点改用本地页面。
场景一直是黑的项目资源缺失，或用了暂不支持的功能。重新导入项目；错误提示会指出卡在哪一步。
频谱没有柱子音频采集权限被拒绝。在隐私与安全性里授权，然后把频谱关掉重开。
壁纸自己暂停了四条暂停规则里有一条生效了。检查是不是在用电池、处于空闲，或别的应用在前面。

它不做什么

  • 不会给静态图片做动画；那部分交给 macOS。
  • 不运行 Wallpaper Engine 本体。场景项目由应用自己的 Metal 渲染器绘制，围绕引擎独占功能制作的项目可能不会和 Wallpaper Engine 里一样。
  • 不会在 Mac 之间同步播放列表或设置。设置可以导出成文件再导入。
