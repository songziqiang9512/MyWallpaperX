从一张喜欢的壁纸开始

快速上手

本地视频、网页作品、实时场景，都可以成为桌面。先选内容，再按自己的习惯调整播放。

  1. 找到内容

    本地视频从「我的视频」导入；Web 与 Scene 作品从「创意工坊」浏览和下载。

  2. 设为壁纸

    在对应素材列表中选中作品，使用「设为壁纸」。工坊作品需要先完成下载。

  3. 调整到舒服

    用音量和暂停控制桌面；Web、Scene 可在详情的「属性调节」中查看作者提供的选项。

Video · 让影像留在桌面

视频壁纸

适合风景、动画片段和循环影像。画面来自视频文件，使用方式最直接。

可以做什么

  • 在「我的视频」导入本地视频，使用「特别喜爱」、播放列表和「最近使用」整理素材。
  • 在播放设置中选择循环、顺序或随机播放，按需要设置自动切换。
  • 调整播放速率。通过「视频填充模式」选择「完整显示」或「填充屏幕」。

用得更舒服

  • 优先选择与屏幕比例接近的视频。「填充屏幕」可能裁切边缘，「完整显示」可能留边。
  • 挑选首尾衔接自然的短片，循环时更连贯。
  • MP4、MOV 等容器里的编码也要能被 macOS 解码；不能播放时先用系统播放器检查文件。

「设置 › 壁纸质量」中的「视频画质」为「原片」，播放已有文件的规格。Pixabay 新下载有多个可用规格时会让你选择，默认选最高的可用规格。播放时使用下载的文件。

视频设置与作者属性的区别视频使用应用的音量、速率和播放模式，没有 Web、Scene 那样的作者自定义属性面板。视频填充模式适用于 Video 壁纸。

Web · 把网页变成桌面

网页壁纸

时钟、信息面板、网页动画与交互画面。内容由网页及其资源组成，具体表现取决于作者的设计。

可以做什么

  • 在创意工坊选择 Web 类型，下载完成后从「我的下载」播放。
  • 打开详情中的「属性调节」，修改作者开放的颜色、文字、开关或其他选项。
  • 支持的作品可以响应鼠标或音频；只有作品本身提供这些行为时才会生效。

使用技巧

  • 先按默认属性播放，再逐项修改，方便判断某个选项的作用。
  • 天气、在线图片等远程内容可能需要网络；下载完成不代表全部内容都能离线运行。
  • 遇到空白或缺少内容，先查看下载任务或列表中的失败、缺少依赖提示；反馈时保留作品链接和现象。

在「设置 › 壁纸质量」的「网页壁纸帧率建议」中，可选「随显示器（最高 60 FPS）」或「跟随动画帧率」。后者采用你设置的动画帧率。只有作者代码使用此建议时，它才会影响网页动画。

保留完整项目Web 壁纸通常不只是一个 HTML 文件。不要从下载目录里单独搬走网页、图片或脚本；依赖其他作品的预设也需要对应基础内容。不同作品的兼容情况可能不同。

Scene · 让场景实时生长

实时场景

场景由图层、材质和动画实时组合，不是一段预先录好的视频。支持的作品可以呈现景深层次、粒子、动态文字及响应效果。

可以做什么

  • 在创意工坊选择 Scene 类型，下载后设为桌面。
  • 在「属性调节」中更改作者开放的颜色、开关、数值、文字或图片选项。
  • 使用统一的播放、暂停和音量控制，按需开启节能策略。

使用技巧

  • 在「设置 › 壁纸质量」调整场景质量和帧率。
  • 先测试默认效果，再调整特效相关属性；复杂作品的流畅程度也取决于内容本身。
  • 画面缺层、效果异常时，对照默认属性，保留作品链接、截图和现象以便反馈。

Scene 壁纸质量

直接调整画质时，需要重新准备的设置会自动应用。场景以新设置重新运行，原来暂停的场景仍会暂停。如果导入的设置还没应用，或自动应用失败，可以点击重新应用当前场景。

场景品质预设与动画帧率。低、中、高、超高预设分别请求 10、15、25、30 FPS，并一起调整 Scene 画质。动画帧率可单独输入 10–120 的整数。手改后的组合与预设不同时显示「自定」，「恢复默认画质」把请求值恢复为 60 FPS。显示刷新率和作品负载会限制实呈帧率，混合刷新率的显示器共用至多 60 FPS 的上限。

场景抗锯齿。可选无、MSAA ×2 或 MSAA ×4。场景重新准备后，受支持设备上的兼容 3D 模型场景可采用所选档位，并可包含兼容的二维图层。纯二维或其它不满足条件的情况沿用单采样。

场景后处理。「禁用」关闭全景泛光，「启用」保留普通泛光，「超高」保留作品的 HDR 效果并以 SDR 显示。至少连接一台支持 HDR 的显示器时，可选「超高（显示 HDR）」以输出更亮的高光。它需要作品启用 HDR，亮度受各屏幕当前余量限制。条件不满足的屏幕继续按 SDR 显示。两种超高之间可即时切换。没有支持 HDR 的显示器时，已保存的显示 HDR 选择会标为「超高（显示 HDR 不可用）」，画面按 SDR 输出。

纹理、光照与反射。纹理分辨率可选自动、高质量、高性能，只调整有合适规格的纹理。阴影档位作用于作品中受支持的阴影。体积照明可禁用，也可选高或超高来调整点光体积的精度。关闭场景反射会移除可选实时反射，作者明确编排的环境效果可能保留。

兼容程度因作品而异Scene 兼容仍在持续完善。下载成功不等于每种特效、脚本或交互都能完整呈现，也不保证与 Wallpaper Engine 的画面完全一致。没有显示的属性，不一定是应用遗漏，也可能是作者未开放。

创意工坊与下载

发现与管理

通过 Steam 账号浏览作品、管理订阅和获取壁纸。Video、Web、Scene 的下载入口在同一个模块中。

搜索与筛选→按提示登录 Steam→下载作品→在我的下载中播放

找到合适的作品

  • 使用工具栏的 Steam 账号入口登录，按提示完成二维码或账号验证。
  • 先筛选内容类型，再搜索主题；「我的订阅」用于查看账号的订阅作品。
  • 详情中可以查看作品信息，并通过作者入口继续发现作品。

读懂下载任务

  • 工具栏下载按钮显示队列、进度和失败原因。
  • 失败项目可点「重试」。先处理提示中的网络、登录或磁盘问题，再重试。
  • 「全部清除」只清理已完成、失败和取消记录，不打断活动任务，也不删除已下载文件。
移除、删除源文件、取消订阅是三件事从「我的下载」移除，默认保留磁盘文件和其他列表；仅勾选「删除磁盘的源文件」才删除文件，无法撤销。取消订阅不删除本地文件；下载面板的「全部清除」只整理任务历史。

让素材各归其位

素材管理

我的视频／我的图片

分别导入并管理本地视频与图片；卡片可拖到侧边栏的播放列表中快速添加。

我的下载

统一管理创意工坊、Pixabay 等在线来源已下载的内容。浏览页用于发现作品，资料库用于播放和整理。

所有播放列表

第一个卡片用于新建列表。列表可混合图片、视频、Web 和 Scene；右键编辑名称、封面与描述。

特别喜爱／最近使用

特别喜爱汇集已标记爱心的本地及已下载壁纸；最近使用按壁纸去重保留最近成功播放的 50 项。未下载的浏览结果需先下载才能加入。

移除只影响当前页的关系在「特别喜爱」移除只取消喜爱，在「最近使用」只移除播放记录，在自建列表只移除该列表成员；默认都保留源文件和其他列表。「文件 → 导入」用于本地视频／图片，不能直接导入 Web 或 Scene 项目。

播放、声音与节能

统一控制

Video、Web、Scene 共用播放／暂停、音量与静音，以及以下四项节能策略。你不用为每个引擎分别设置。

设置 → 节能与暂停
开关什么时候暂停
其他应用焦点时暂停切换到其他普通应用工作时。MyWallpaperX 自身和访达不算“其他应用”。
其他应用全屏时暂停当前进入其他应用占据的全屏空间时。
未连接电源时暂停播放电脑使用电池供电时。
电脑不活跃时暂停播放无操作达到所选的不活跃时间后；可在该开关下调整等待时长。

暂停后怎样恢复

只要仍有一项已启用的暂停条件成立，壁纸就会保持暂停。条件解除后才能自动继续；你手动暂停的壁纸仍需手动恢复。

声音与音频响应

音量控制壁纸自身的声音，不会凭空给无声作品添加音轨。跟随系统声音变化的效果，还需要作品支持、对应设置及 macOS 权限。

先从简单的节能组合开始经常全屏工作，可先打开“其他应用全屏时暂停”；笔记本再按需要开启电池暂停。需要进一步降低 Scene 的运行开销时，可调低动画帧率。

系统与屏保

桌面之外

壁纸不只活在桌面上。下面这些设置把它接到额外的显示器、系统桌面图片、锁屏和开机启动。

多屏

「显示设置」里的多屏支持让壁纸出现在每一块显示器上。关掉后只有主屏播放，其他屏幕保留系统图片。

同步系统壁纸

同步系统壁纸会在壁纸变化时更新 macOS 桌面图片：视频取一帧静态画面，Web 和 Scene 取启动过渡之后的一帧。这样调度中心、空间和登录界面看到的都一致。静态图片始终直接应用。

屏保

应用自带系统屏保扩展。在系统设置 › 屏保里选择 MyWallpaperX，再挑一个本地视频，它会静音循环。屏保读的是自己那份拷贝，所以从资料库删掉壁纸不会弄坏它——删除时应用会保留这份拷贝，并告诉你它在哪里。

开机与启动

开机自启动让应用随登录启动。启动时恢复播放恢复上一次的视频、Web 或 Scene 壁纸；关掉后启动时不播放，桌面保留系统图片。静态图片由 macOS 处理，不受这两个开关影响。

外观与单击

APP界面色调跟随系统外观，也可以固定浅色或深色。卡片单击操作决定单击卡片是立即播放还是先打开详情；回车键和右键菜单各有自己的动作。

视频填充模式

视频填充模式提供「完整显示」和「填充屏幕」。「完整显示」保留整个画面，可能留边。「填充屏幕」铺满显示器，可能裁掉画面边缘。

音频频谱

频谱把系统音频画成柱状，贴在桌面底部。只对视频壁纸生效，第一次开启需要音频采集权限。柱子数量、颜色、X/Y 位置和峰值帽都可调；这个效果会带来少量每帧开销。

歌曲信息

壁纸歌曲信息在支持的 Scene 和 Web 壁纸上显示当前曲目与封面。macOS 第一次会请求访问 Apple Music 的「自动化」权限；在授权之前开关不会生效。如果你拒绝过，去隐私与安全性 › 自动化重新允许，再把开关打开。

登录，一次一个提示

Steam 登录

创意工坊通过应用内置的 Steam 服务与 Steam 通信。你可以扫码登录，也可以用账号名和密码登录；无论哪种，Steam 都可能再要一次确认，会话才算可用。

记住登录勾选「记住我」会把会话存进钥匙串，下次启动直接恢复、不再询问。不勾选就下次重新登录——这不是失败。只有明确提示「会话无法保存」才是保存失败。反馈问题时不要附上密码、验证码、二维码图片或会话令牌。
二维码扫不上 / 一直等确认

用 Steam 手机应用扫码。点二维码，或按 Tab 到「放大二维码」看更大的图。二维码失效就刷新再扫新的。在扫码和密码之间切换会取消上一次尝试。

请在 Steam 手机应用中确认这次登录

扫码通过或密码被接受之后，仍可能需要在手机上确认。请求会以设备名「MyWallpaperX SteamService」出现在 Steam 应用里。保持面板打开并在手机上确认；关闭面板或按 Esc 会取消这次登录。

上一次的验证码被拒绝

Steam 这次要的是令牌验证码或邮箱验证码。为本次尝试输入新码；旧码、输入错误或来源不对都会被拒绝。走邮箱时，面板会显示验证码发到了哪个域名。

登录被拒绝 · accessDenied

Steam 拒绝了凭据或账号访问。用登录用的账号名和密码，不是个人资料的显示名。密码错误和账号受限都会落在这里；请到官方 Steam 客户端核对账号状态。

authExpired / 保存的登录被拒

保存的会话已过期或被撤销。从账号菜单用目标账号重新登录。恢复失败时会区分网络问题和会话过期；网络问题会保留已保存的登录，可以直接重试。

网络超时

登录没能在限定时间内完成。可能是网络、代理、Steam 可用性，或手机确认迟迟未点；单凭超时不能证明密码错误。先确认手机上的确认状态和网络，再重试。

rateLimited

Steam 正在限流。等一会儿再试，不要反复刷新二维码或重复提交密码。

登录成功，但会话没能保存

这次会话可用，但写入钥匙串失败，下次可能还要登录。这和「没勾记住我」是两回事。如果反复出现，记录提示和应用版本；不要一上来就删钥匙串。

Steam 服务不可用 / 版本不兼容 / 连接断开

内置的 Steam 服务没起来、已退出，或协议版本不一致。请更新或重装完整的应用，不要混装不同构建的组件。连接断开时先重启再试；持续出现请附上运行版本。

不登录能做什么

公开的创意工坊页面和搜索在登录前就能浏览。下载、订阅和「我的订阅」需要完成登录。

下载失败，先读懂这一行

原因与处理

先打开工具栏「下载任务」，看失败发生在哪一步：下载清单、获取 CDN 授权、下载数据块，还是保存本地文件。同一个错误数字，出现在不同阶段时需要检查的地方不同。

下载走 SteamKit 的 CDN 客户端。单个清单不超过 8 GiB 或 20 万个文件；清单和分块传输各最多尝试 3 次，403 之后额外允许一次重新鉴权。一直卡在同一阶段的失败，反复重试并不会变好。

报错可能长这样 · 格式示例下载清单失败（HTTP 503，节点 <服务器>，已尝试 <次数> 次）。请检查网络及代理设置，稍后重试。
HTTP 503 / 500 / 502 / 504 · network

可能的原因

服务、内容节点或中间网络链路暂时不可用。浏览成功不代表下载节点也能连通；503 本身不能证明是 App 版本或 SteamKit 缺陷。

接下来这样做

稍后重试；检查当前代理是否覆盖 App 的下载连接，或换一条可用网络比较。多个作品同时失败时，保留节点、时间与完整提示。

HTTP 401 · authExpired

可能的原因

当前下载授权或登录会话失效。

接下来这样做

工具栏账号菜单重新登录，再对失败任务点「重试」。

HTTP 403 · accessDenied／未提供有效的 CDN 授权

可能的原因

节点拒绝访问，可能与账号对内容的访问权限、CDN 授权或代理有关；不等于一律密码错误。

接下来这样做

检查账号是否有访问该作品所需的权限，确认网络和代理设置；重新登录后重试。若提示 staging access denied，则应检查本地目录权限。

HTTP 429 · rateLimited

可能的原因

Steam 限制了请求频率。

接下来这样做

等待后再试，避免连续重复创建任务。应用已对部分临时错误做有限次数的自动重试。

HTTP 404 · unsupportedContent／item has no content manifest

可能的原因

节点没有提供对应内容，或作品没有可下载清单；作品更新、不可访问或不属于 Wallpaper Engine 也可能导致内容不可用。

接下来这样做

重新打开作品，确认链接和访问权限后再试。作品已删除、非目标类型或没有有效内容时，重复点击下载无法解决。

diskFull · 磁盘空间不足

可能的原因

下载暂存或最终保存所在磁盘空间不足。

接下来这样做

释放相应磁盘空间再重试；提示「下载暂存已保留」时，可在原任务重试。保存前仍需要足够的工作空间，不要只看压缩包标称大小。

integrity · 内容校验失败／staging identity changed

可能的原因

下载内容校验、文件长度或目录身份不一致；也可能是下载中途移动或改写了暂存文件。应用会停止这次不安全的保存。

接下来这样做

停止外部移动或编辑相关目录后重试；反复出现时保留完整报错和作品 ID。不要手工改校验文件来跳过检查。

manifest requires a nonempty root project.json／manifest path…

可能的原因

内容结构缺失，或清单路径、大小等不满足安全要求；这类失败并非一般网络重试就能解决。

接下来这样做

确认是完整的 Wallpaper Engine 作品。保留原始错误用于反馈，不要自行拼凑文件夹后当作已下载内容。

服务响应超时／连接已中断／helperUnavailable / protocolMismatch

可能的原因

可能是辅助服务没有启动、退出、版本不匹配或请求没有完成；不能仅凭这类提示判断为 Steam 服务器故障。

接下来这样做

连接中断先重开 App；组件不可用／版本不兼容则更新或重装完整 App。反馈时说明是否有多个版本的 App 同时存在。

下载已停止，但暂存目录无法安全清理／暂存清理失败

可能的原因

任务已停止或内容状态已保存，但临时文件清理失败；不是让你手动删除整个壁纸目录。

接下来这样做

先看任务与「我的下载」的实际状态。保留提示，检查目录权限或外部文件操作；持续失败再反馈。

进度到 100% 也要等“已完成”传输后还有校验和保存。排队、连接中或保存中不一定持续显示速度；失败后处理原因再点重试。「全部清除」只清任务历史，保留活动任务和下载文件。

如果下载已完成但 Web／Scene 缺少依赖，可在「我的下载」筛选「不可用」，或打开详情查看基础作品提示。这是内容依赖问题，与 HTTP 下载失败不同。反馈请附：应用版本与运行位置、作品链接／ID、时间、完整错误、单个还是全部作品失败，以及网络／代理是否开启。

遇到问题，从这里检查

常见问题
壁纸突然不动了，是程序卡住了吗？

先检查是否手动暂停，再看节能开关是否因焦点、全屏、电池或不活跃而触发。Scene 也受这些开关控制；它并不是只有在访达或 MyWallpaperX 获得焦点时才允许播放。

为什么 Web 壁纸空白，或时钟之外的内容不显示？

确认下载完整，并查看下载任务或列表中的失败、缺少依赖提示。需要联网的天气、图片或其他服务，在离线或远端不可用时可能缺失。单个 HTML 文件不等于完整壁纸项目。

Scene 能播放，但与工坊预览不一样？

先恢复自己改过的作者属性或对照默认值。部分特效、脚本和交互可能尚未完整兼容。反馈时附上作品链接、异常位置、应用版本和截图，便于区分内容设置与兼容问题。

下载失败，出现 503 怎么处理？

到下载故障排查查看 HTTP 503、401、403、429、磁盘和校验错误的区别；登录异常可查登录排查。保留完整提示，单凭数字无法确认根因。

清空下载任务后，壁纸为什么还在？

任务历史与本地内容分开管理。「全部清除」不删除文件；请到「我的下载」移除壁纸，默认仍保留源文件，勾选「删除磁盘的源文件」才删除文件。取消订阅不会自动删除本地文件。

如何检查更新或反馈问题？

从 MyWallpaperX 菜单选择「检查更新…」；「关于 MyWallpaperX」可查看应用信息。反馈请说明壁纸类型、复现步骤、作品链接或本地文件格式，附上错误提示。不要提供 Steam 密码或验证码。

删掉壁纸后屏保不播了

屏保用的是它自己那份拷贝，删除资料库条目时会保留。到系统设置 › 屏保里重新选一次视频；如果那份拷贝也被清掉了，重新添加该作品再选一次。

副屏一直是静态图片

打开设置 › 显示设置里的「多屏支持」。关掉时只有主屏播放，其他屏幕保留 macOS 桌面图片，而那个图片可能正被「同步系统壁纸」更新。
