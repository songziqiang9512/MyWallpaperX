从一张喜欢的壁纸开始

快速上手

本地视频、网页作品、实时场景，都可以成为桌面。先选内容，再按自己的习惯调整播放。

  1. 找到内容

    本地视频从「我的视频」导入；Web 与 Scene 作品从「创意工坊」浏览和下载。

  2. 设为壁纸

    在对应素材列表中选中作品，使用「设为当前壁纸」。工坊作品需要先完成下载。

  3. 调整到舒服

    用音量和暂停控制桌面；Web、Scene 可在详情的「属性调节」中查看作者提供的选项。

Video · 让影像留在桌面

视频壁纸

适合风景、动画片段和循环影像。画面来自视频文件，使用方式最直接。

可以做什么

  • 在「我的视频」导入本地视频，使用收藏、标签和最近使用整理素材。
  • 在播放设置中选择循环、顺序或随机播放，按需要设置自动切换。
  • 调整播放速率；通过「视频填充模式」选择完整显示或铺满屏幕。

用得更舒服

  • 优先选择与屏幕比例接近的视频。铺满可能裁切边缘，完整显示可能留有黑边。
  • 挑选首尾衔接自然的短片，循环时更连贯。
  • MP4、MOV 等容器里的编码也要能被 macOS 解码；不能播放时先用系统播放器检查文件。
视频设置与作者属性的区别视频使用应用的音量、速率和播放模式，没有 Web、Scene 那样的作者自定义属性面板。播放速率、视频填充也不是三种引擎的通用设置。

Web · 把网页变成桌面

网页壁纸

时钟、信息面板、网页动画与交互画面。内容由网页及其资源组成，具体表现取决于作者的设计。

可以做什么

  • 在创意工坊选择 Web 类型，下载完成后从「已下载」播放。
  • 打开详情中的「属性调节」，修改作者开放的颜色、文字、开关或其他选项。
  • 支持的作品可以响应鼠标或音频；只有作品本身提供这些行为时才会生效。

使用技巧

  • 先按默认属性播放，再逐项修改，方便判断某个选项的作用。
  • 天气、在线图片等远程内容可能需要网络；下载完成不代表全部内容都能离线运行。
  • 遇到空白或缺少内容，查看详情中的「播放诊断」，核对入口、资源及依赖提示。
保留完整项目Web 壁纸通常不只是一个 HTML 文件。不要从下载目录里单独搬走网页、图片或脚本；依赖其他作品的预设也需要对应基础内容。不同作品的兼容情况可能不同。

Scene · 让场景实时生长

实时场景

场景由图层、材质和动画实时组合，不是一段预先录好的视频。支持的作品可以呈现景深层次、粒子、动态文字及响应效果。

可以做什么

  • 在创意工坊选择 Scene 类型，下载后设为桌面。
  • 在「属性调节」中更改作者开放的颜色、开关、数值、文字或图片选项。
  • 使用统一的播放、暂停和音量控制，按需开启节能策略。

使用技巧

  • 想降低运行开销，可在设置中选择「最高帧率（Scene 引擎）」的 30 档；60 档提供更高的帧率上限。
  • 先测试默认效果，再调整特效相关属性；复杂作品的流畅程度也取决于内容本身。
  • 画面缺层、效果异常时，查看「播放诊断」，保留作品链接和现象以便反馈。
兼容程度因作品而异Scene 兼容仍在持续完善。下载成功不等于每种特效、脚本或交互都能完整呈现，也不保证与 Wallpaper Engine 的画面完全一致。没有显示的属性，不一定是应用遗漏，也可能是作者未开放。

创意工坊与下载

发现与管理

通过 Steam 账号浏览作品、管理订阅和获取壁纸。Video、Web、Scene 的下载入口在同一个模块中。

登录 Steam→搜索与筛选→下载作品→在已下载中播放

找到合适的作品

  • 使用工具栏的 Steam 账号入口登录，按提示完成二维码或账号验证。
  • 先筛选内容类型，再搜索主题；「我的订阅」用于查看账号的订阅作品。
  • 详情中可以查看作品信息，并通过作者入口继续发现作品。

读懂下载任务

  • 工具栏下载按钮显示队列、进度和失败原因。
  • 失败项目可点「重试」。先处理提示中的网络、登录或磁盘问题，再重试。
  • 「全部清除」只清理已完成、失败和取消记录，不打断活动任务，也不删除已下载文件。
清除记录、删除文件、取消订阅是三件事在创意工坊「已下载」列表删除作品，会删除对应的本地内容；取消订阅不会删除本地文件。只想整理任务历史，请用下载面板的「全部清除」。

重试只在失败项显示。先处理失败原因，并确认仍登录该任务所属的 Steam 账号，再点击重新下载。

让素材各归其位

素材管理

我的视频

管理自己导入的视频。「特别喜爱」收集常用作品，「最近使用」找回刚用过的壁纸，标签适合按氛围或用途分类。

我的图片

静态图片有独立的素材列表和标签。想要安静的桌面时，可以直接使用图片壁纸，无需动态播放。

Pixabay 浏览

在线发现素材，通过该模块的「已下载」管理下载内容。若提示需要 API Key，使用工具栏的密钥设置入口完成配置。

工坊已下载

集中管理已获取的 Video、Web、Scene。文件被外部移动或删除后，原条目可能不可用；通过原作品重新下载比只搬回部分文件更稳妥。

先选模块，再操作导入、搜索、筛选和删除的对象取决于当前所在列表。「文件 → 导入」用于当前支持导入的素材模块，不是通用的 Web 或 Scene 文件导入口。

播放、声音与节能

统一控制

Video、Web、Scene 共用播放／暂停、音量与静音，以及以下四项节能策略。你不用为每个引擎分别设置。

设置 → 节能与暂停
开关什么时候暂停
其他应用焦点时暂停切换到其他普通应用工作时。MyWallpaperX 自身和访达不算“其他应用”。
其他应用全屏时暂停当前进入其他应用占据的全屏空间时。
未连接电源时暂停播放电脑使用电池供电时。
电脑不活跃时暂停播放无操作达到所选的不活跃时间后；可在该开关下调整等待时长。

暂停后怎样恢复

只要仍有一项已启用的暂停条件成立，壁纸就会保持暂停。条件解除后才能自动继续；你手动暂停的壁纸仍需手动恢复。

声音与音频响应

音量控制壁纸自身的声音，不会凭空给无声作品添加音轨。跟随系统声音变化的效果，还需要作品支持、对应设置及 macOS 权限。

先从简单的节能组合开始经常全屏工作，可先打开“其他应用全屏时暂停”；笔记本再按需要开启电池暂停。Scene 的 30／60 帧率档位只影响 Scene，不会更改视频原始帧率。

登录遇到问题，按提示处理

Steam 登录

从工具栏 Steam 账号入口开始。二维码登录使用 Steam 手机应用扫码并确认；账号密码登录可能继续要求手机批准、手机令牌或邮箱验证码。请按面板当前提示操作。

“记住登录”保存的是会话按需要勾选「记住登录」。忘记勾选时，下次重新登录不一定是故障；若明确提示「本次登录未能保存」，则是保存失败。不要在反馈中提供密码、验证码、二维码或登录令牌。
二维码扫不出／等待扫码确认

用 Steam 手机应用扫描。点击二维码或「放大二维码」看大图；旧码不可用时点刷新，扫描新码。切换登录方式会取消旧的验证流程。

请在 Steam 手机应用中确认本次登录

扫码或密码通过后，还可能需要手机端确认。保持登录面板打开，去 Steam 手机应用批准此次登录；关闭面板或按 Esc 会取消本次认证。

上一枚验证码被拒绝，请重新输入

核对当前要求的是手机令牌还是邮箱验证码。输入当前这一次登录对应的新验证码；旧码、输错或用错来源都可能被拒绝。邮箱验证还要核对提示的邮箱域名。

登录未完成 · InvalidPassword / accessDenied

Steam 拒绝了凭据或访问请求。使用 Steam 登录账号名与密码，不要把个人资料昵称当账号名；也可能与账号权限有关。先核对登录信息，再在 Steam 官方客户端确认账号状态。

authExpired / Steam token rejected

保存的会话已过期、撤销或被 Steam 拒绝。用工具栏账号菜单重新登录；切换账号时确认正在登录的是需要使用的账号。

Steam 认证等待超时／服务响应超时／network

认证没有及时完成；可能是网络、代理、Steam 服务或手机确认等待超时。确认手机端是否已批准，检查连接后重新登录。单凭超时不能断定密码错误。

rateLimited / RateLimitExceeded

Steam 暂时限制请求。等待一段时间再尝试，避免连续刷新二维码或反复提交密码。

已登录，但本次登录未能保存

此次会话已经登录成功，但保存登录状态失败，下次可能需要重登。它与「未勾选记住登录」不同；如果重复出现，保留完整提示和应用版本用于反馈，不必先删除整个钥匙串。

Steam 服务组件不可用／版本不兼容／连接已中断

组件不可用或协议不兼容通常需要更新或重新安装完整 App；不要混用不同构建里的组件。连接中断可先重开 App 再试；持续发生时同时记录运行中的 App 版本和来源。

下载失败，先读懂这一行

原因与处理

先打开工具栏「下载任务」，看失败发生在哪一步：下载清单、获取 CDN 授权、下载数据块，还是保存本地文件。同一个错误数字，出现在不同阶段时需要检查的地方不同。

报错可能长这样 · 格式示例下载清单失败（HTTP 503，节点 <服务器>，已尝试 <次数> 次）。请检查网络及代理设置，稍后重试。
HTTP 503 / 500 / 502 / 504 · network

可能的原因

服务、内容节点或中间网络链路暂时不可用。浏览成功不代表下载节点也能连通；503 本身不能证明是 App 版本或 SteamKit 缺陷。

接下来这样做

稍后重试；检查当前代理是否覆盖 App 的下载连接，或换一条可用网络比较。多个作品同时失败时，保留节点、时间与完整提示。

HTTP 401 · authExpired

可能的原因

当前下载授权或登录会话失效。

接下来这样做

工具栏账号菜单重新登录，再对失败任务点「重试」。

HTTP 403 · accessDenied／未提供有效的 CDN 授权

可能的原因

节点拒绝访问，可能与账号对内容的访问权限、CDN 授权或代理有关；不等于一律密码错误。

接下来这样做

检查账号是否有访问该作品所需的权限，确认网络和代理设置；重新登录后重试。若提示 staging access denied，则应检查本地目录权限。

HTTP 429 · rateLimited

可能的原因

Steam 限制了请求频率。

接下来这样做

等待后再试，避免连续重复创建任务。应用已对部分临时错误做有限次数的自动重试。

HTTP 404 · unsupportedContent／item has no content manifest

可能的原因

节点没有提供对应内容，或作品没有可下载清单；作品更新、不可访问或不属于 Wallpaper Engine 也可能导致内容不可用。

接下来这样做

重新打开作品，确认链接和访问权限后再试。作品已删除、非目标类型或没有有效内容时，重复点击下载无法解决。

diskFull · 磁盘空间不足

可能的原因

下载暂存或最终保存所在磁盘空间不足。

接下来这样做

释放相应磁盘空间再重试；提示「下载暂存已保留」时，可在原任务重试。保存前仍需要足够的工作空间，不要只看压缩包标称大小。

integrity · 内容校验失败／staging identity changed

可能的原因

下载内容校验、文件长度或目录身份不一致；也可能是下载中途移动或改写了暂存文件。应用会停止这次不安全的保存。

接下来这样做

停止外部移动或编辑相关目录后重试；反复出现时保留完整报错和作品 ID。不要手工改校验文件来跳过检查。

manifest requires a nonempty root project.json／manifest path…

可能的原因

内容结构缺失，或清单路径、大小等不满足安全要求；这类失败并非一般网络重试就能解决。

接下来这样做

确认是完整的 Wallpaper Engine 作品。保留原始错误用于反馈，不要自行拼凑文件夹后当作已下载内容。

服务响应超时／连接已中断／helperUnavailable / protocolMismatch

可能的原因

可能是辅助服务没有启动、退出、版本不匹配或请求没有完成；不能仅凭这类提示判断为 Steam 服务器故障。

接下来这样做

连接中断先重开 App；组件不可用／版本不兼容则更新或重装完整 App。反馈时说明是否有多个版本的 App 同时存在。

下载已停止，但暂存目录无法安全清理／暂存清理失败

可能的原因

任务已停止或内容状态已保存，但临时文件清理失败；不是让你手动删除整个壁纸目录。

接下来这样做

先看任务与「已下载」的实际状态。保留提示，检查目录权限或外部文件操作；持续失败再反馈。

进度到 100% 也要等“已完成”传输后还有校验和保存。排队、连接中或保存中不一定持续显示速度；失败后处理原因再点重试。「全部清除」只清任务历史，保留活动任务和下载文件。

如果下载已完成但 Web／Scene 缺少依赖，去「已下载」的「缺少依赖」筛选或作品详情查看基础作品提示。这是内容依赖问题，与 HTTP 下载失败不同。反馈请附：应用版本与运行位置、作品链接／ID、时间、完整错误、单个还是全部作品失败，以及网络／代理是否开启。

遇到问题，从这里检查

常见问题
壁纸突然不动了，是程序卡住了吗？

先检查是否手动暂停，再看节能开关是否因焦点、全屏、电池或不活跃而触发。Scene 也受这些开关控制；它并不是只有在访达或 MyWallpaperX 获得焦点时才允许播放。

为什么 Web 壁纸空白，或时钟之外的内容不显示？

确认下载完整，查看播放诊断中的入口和依赖提示。需要联网的天气、图片或其他服务，在离线或远端不可用时可能缺失。只给一个 HTML 文件并不等于完整壁纸项目。

Scene 能播放，但与工坊预览不一样？

先恢复自己改过的作者属性或对照默认值，查看诊断提示。部分特效、脚本和交互可能尚未完整兼容。反馈时附上作品链接、异常位置、应用版本和截图，便于区分内容设置与兼容问题。

下载失败，出现 503 怎么处理？

到下载故障排查查看 HTTP 503、401、403、429、磁盘和校验错误的区别；登录异常可查登录排查。保留完整提示，单凭数字无法确认根因。

清空下载任务后，壁纸为什么还在？

任务历史与本地内容分开管理。「全部清除」不删除文件；需要移除工坊壁纸时，在工坊「已下载」列表中删除。取消订阅同样不会自动删除本地文件。

如何检查更新或反馈问题？

从 MyWallpaperX 菜单选择「检查更新…」；「关于 MyWallpaperX」可查看应用信息。反馈请说明壁纸类型、复现步骤、作品链接或本地文件格式，附上错误提示。不要提供 Steam 密码或验证码。
