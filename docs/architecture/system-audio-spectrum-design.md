# 共享音频频谱响应设计

> 状态：2026-10-17固定分贝链已实施；两段真实Music同源对照、代表样式实际窗口与独立审查完成。正常实例供用户继续测试，不声明官方私有公式、全作品或完整歌曲一致。

## 目标与职责

让有效音乐频段既有可见高度，又保留各自起伏；减少悬殊落差、连片压顶及整组随最强频段缩放。保留作者柱数、坐标、镜像、插值、颜色、发光和布局。Video现有产品只有柱形，不增加环形选项。

SystemAudioSpectrumService独占采集及约30Hz发布；SystemAudioSceneSpectrumAnalyzer独占FFT、频率轴、固定频率均衡和高度包络。Video只投影最终高度与既有风格，Web/Scene消费同一响应。不新增采集器、provider或最终输出owner。`PlaybackSpectrumDelivery`由控制面更新有身份的进程目标，采集后台直接向有界transport发布完整数组；普通帧不经主App的AppKit队列。停止/替换撤权仍保持Scene capture scope与daemon generation校验。

Video overlay 需求同时要求设置开启、未暂停且存在运行中的 Video transport；目标创建、退出、崩溃与回收都重新核对需求。Web/Scene 保留各自作者需求，保留中的旧 Video 也算真实接收端。没有接收端时不为设置开启维持采集或 FFT；空 Web 预热不建立需求，重新播放自动恢复。撤销 Video/Web 需求时先向旧合法目标投递一次有序静音屏障，随后拒绝迟到帧并清除父端快照，避免暂停残留柱高。

Video helper 初始化只挂频谱容器，首次开启时才按当前柱数、颜色、偏移和窗口布局建立子层，并恢复首次开启前已接纳的频谱高度。空子层数组就是尚未建立的事实，不另设生命周期标记。首次建立后关闭保留原对象和 0.18 秒淡出；再次开启复用，柱数变更仍沿原重建与清零规则。

连续PCM → 去DC/Hann/标定FFT → 64频段幅度密度 → 固定频率补偿 → 固定分贝窗口/柔和映射 → 最终高度逐带包络 → 16/32/64及Video均值投影 → 既有绘制。

原 CaptureBuffer 独占连续 PCM 窗和原始数值处理，Service 将当前完整窗口的不变快照交给原 Analyzer；Analyzer 不再维护第二份 PCM 历史或重复扫描已解码样本。格式与通道变化、捕获时钟、FFT padding 和算术溢出的有限输出边界仍由各自实际消费点负责。Levels 仅保存不可变的左右 64 带成品，Scene 读取时才按原面积均值算法派生 16/32 带；Video 和 Web 无需为没有消费者的粗频带付费。Overlay 消费同一成品，保持先求立体声均值再投影的顺序，不重新校验已完成的高度，也不另持包络。

采集帧仅交付真实分析消费的有符号声道，不携带诊断派生的整流单声道数组。首个有声 Debug 日志在原 Service 的未记录分支按需取同帧整流均值峰值，记录后不继续逐窗归并；FFT、包络与对外六组数组只沿原有符号声道链。

## 决策与退出

- 对齐参考项目的处理职责与顺序，按本项目独立实现标准DSP步骤，不复制或移植其源码。当前约85ms窗及频率身份先保留，避免同时任意重排作者频率。
- 频段取幅度均值，避免宽频段仅因包含更多FFT格而更高；FFT尺度绑定样本数与实际窗。采用固定频率补偿平衡音乐的频率倾斜。
- 固定-100…-10dB窗口保留弱频段细节，标准smoothstep预留0.96顶部；参数由同一真实音乐输入对照校准，再用独立片段复核。最终高度包络上升30ms/回落140ms，时间由捕获时间决定。
- 撤去最强频段跟随参考、带内可听度乘数、能量域幂包络及消费者二次显示曲线。不开每帧min/max拉伸、逐柱自动拉满、随机动作或邻带扩散。零输入落回零；无能量频段不伪造运动。
- 六组Scene数组先得到同一64带最终高度再均值投影。Video同样取这组数据；原生灵敏度仅是静态高度风格，不持有另一FFT、时钟或包络。大于64根显示柱不能获得额外独立频率信息。
- scope、格式、reset、迟到时间和失败仍由现有采集生命周期裁决。迟到格式不得重置当前历史；停用消费者清零不误清其他消费者。无效数值局部归零。

## 验收与边界

1. 行为门覆盖幅度标定、弱频段保留、不同频段输入独立、无峰值竞争、固定音量响应、均值投影、时间包络、静音、scope/格式/迟到回调与IPC。
2. 同一真实音乐PCM分别经过本项目与参考行为探针，对照高度分布、逐带变化、压顶和静音，不用单音/粉噪结果代替真实音乐。原始音乐只在有界临时验证中使用，收尾删除。
3. Debug构建及签名后，在隔离样本中验证Scene柱形/环形、Web柱形/环形与Video真实绘制，作者源码不改；保留正常实例供用户测试。
4. 独立DSP及接线/视觉对抗审查绑定冻结源码，修订后复核。参考、官方公开数组、合成测试和真实音乐画面的结论分别标明。Web音频窗口验收要求两帧motion；不能用前景preview遮挡实时canvas后宣称动态通过。
