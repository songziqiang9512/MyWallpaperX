# 粒子 Vortex 后继设计

## 目标与差距

恢复真实作者 `vortex_v2` 声明的运动，并保持既有粒子绘制、子系统和最终合成。基线 `41add9df` 已接通普通 v2；当时 flags2 仍局部跳过。四份已核对的真实样本有五处声明，包含普通模式、flags2、音频及省略参数；普通模式与 flags2 分开验收，不把局部接线算作整个能力完成。

与文字投影边界、斜光相比，本项有明确被跳过的作者职责，两份样本分别依赖普通涡旋和带径向初速度的 flags2。先交付有完整反例验收的普通模式，经原 Sprite/Rope/Trail、child 和唯一 compositor 呈现；当时 flags2 保持明确诊断，本批继续修复长期半径稳定性。

## 唯一职责与取舍

沿 `DefinitionParser → typed operator → prepared execution plan → Simulator → existing geometry/compositor` 接入。classic 与 v2 在已有声明中保留版本身份，共用几何与模拟 owner；版本分别决定字段/flags 准入，不能简单改名。计划在准备期建立，普通帧只消费 typed 参数、现有 fixed-step、audio、instance snapshot 与 CP 值，不新增解析、诊断扫描、时钟或缓存。

CP 复用已有位置/方向来源。仅当相应作者行为和组合已确认才开放，未知动态值局部拒绝，不伪造零中心。安全错误拒绝最小 operator，其他健康 operator 与层继续工作。有限状态采用现有原子写入，未知字段不静默忽略。

## 待裁决行为

[官方公开合同](https://docs.wallpaperengine.io/en/scene/particles/component/operator.html#vortex)说明标准/环形、内外速度/距离、CP、轴及中心作用；不公开完整 wire 和积分语义。[已验方向证据](../../history/runtime-evidence-index.md#e-particle-vortex-direction)确认正 Z/正 speed 方向、原点默认对照与 outer 外仍运动；不证明力度或整个 flags2 行为。

同场多速度/半径与普通粒子时钟已排除 audio0、初始径向速度及隐藏 Z 分量的解释；轴长度 1/2/4 无可见差分。25 FPS 设置下，普通涡旋幅度小于等值 gravity，但尚无实际帧率记录或跨设置对照。`1 / sqrt(2)` 候选在慢速大转角点的中心时刻有偏差；必须比较蓝钟时间区间内的同一条轨迹与观测误差盒，不能把人工 CUA 坐标当严格 golden 或直接定为通用力度换算。用 25→60→25 同输入、同粒子时钟对照裁决帧率混淆，恢复原设置；不继续重复已排除的假设。

flags2 官方长时半径约120，带径向初速度的短寿命包络也受约束。项目的“径向速度投影 + 完整向心加速度”候选在444秒缩至约115，已被反例否定；否定该数值候选，不用短时近似绕过长期收缩。约束状态归入现有 particle state，具体方案见下。

原始输入、有效 PNG、CUA 人工估计及误差分别保留，黑帧、旧标题或出界时钟不作证据。普通模式按下述裁决实施，交付仍须通过独立数值与原生可见验收；项目数值方案与官方完整内部算法不作等价宣称。

## 已交付裁决：普通模式

只开放 flags0、显式 finite inner/outer distance/speed、默认/正Z轴、静态原点 CP0、无音频的 v2。使用同一切向加速度算法，在准备期仅对 v2 的作者速度乘项目经验响应 `0.72`；classic 和 audio 原有数值保持不变。该两位有效数字来自同场低速/多半径观测，不是官方内部公式；已在新的独立输入包返回前冻结，不依据 holdout 结果继续调参。新输入 t12±2 的完整控制点帧与响应相容，必须由最终代码在统一时间区间验证两轴误差，而非只比较幅度。

这修订原先不采用经验系数的取舍：有可证伪输入/误差/独立保留数据的项目响应可以交付，官方内部未知本身不阻止恢复明确的运动。25→60 的 GUI 入口经有限可用操作仍无法打开，未改配置；跨帧率一致性保持未验证，不编造实际 FPS 或扩大 parity 声明。若正式 holdout 或真实组合出现反例，撤回此新增准入，不继续拟合系数。该普通模式批次未开放 flags2；动态/移位/旋转 CP、非Z轴、audio、缺参数仍局部拒绝。

## 本批裁决：保半径模式

开放单个 flags2，要求唯一局部空间 flags0 Movement 位于其前方、gravity 为省略/解析后 nil、标量0或 exact三维0（沿用既有 Movement 的缺失/解析失败默认化，不新增完整 malformed 合同）；拒绝 General world-space；其他 operator 仅允许颜色、大小、透明度与自身角度变化，不允许修改位置/速度的组合。其余 v2 字段/CP 准入沿用普通模式，准备期判断拓扑，不按样本分派。

首次有效 vortex 在 Movement 后记录径向半径并移除径向速度，保留一次正常出生位移。半径是现有 `SceneParticleState` 的可选字段；出生为 nil，随粒子死亡释放，自动进入已有 frame snapshot/restore。后续仍由 Movement 执行 drag，以切向速度和原半径计算转角，同时旋转位置与速度方向，轴向速度保持原有积分。每步用记录的半径重建位置，避免 Euler 向心修正造成收缩；不保存第二份位置、相位或时钟。Vortex 在原作者顺序施加切向增量，暂沿用 v2 项目响应，不能宣称官方相位一致。

动态 CP/角度使约束失效时，Movement 清除半径并恢复普通积分；重新进入支持范围后按当前位置重新锚定，不拉回陈旧轨道。原子检查完整位置/速度后提交；拒绝危险数值的当前粒子结果。原点零半径不强行生成轨道。

验收：真实 parser 到 simulator 的 444 秒零/径向初速、drag/负速度、固定步分区、失效恢复、frame rollback 与新出生隔离；普通 v2/classic/audio 邻接回归。冻结 App 串行对比真实 3792249095 的粒子环及完整合成。长期半径和短寿命包络只证明几何约束；官方长期相位、其他 force 组合和跨 FPS 继续独立验收。若稳定性或真实可见结果出现反例，不开放该组合。

## 验证与退出

测试必须穿过真实 parser、prepared plan、simulator，覆盖真实字段、正负/零速度、时间分区、径向初速、CP 与非法输入反例；保持 classic/audio/child 邻接回归。冻结 Debug 构建后串行运行官方对照与原生 App，记录输入/App 身份、同模拟时刻轨迹、GPU completion、唯一 compositor 和退出排空。真实样本检查恢复的粒子层及健康邻层，不只看非黑截图。

独立审查绑定最终 diff 和证据。达到可见验收后重新比较下一项缺口，未闭合范围留在现有能力台账；未知 profile 不宣称支持。实现或证据出现反例时撤回相应新增准入，保留原运行路径与最小复现。官方全数值、全样本、性能和发布结论分别验收。
