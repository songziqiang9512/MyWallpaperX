### E-MASK-SLOT-COMBO: texture-slot combo 由贴图存在自动设置

- 2.8.42 取证快照显示：59 份 shader 各有 1 处 `sampler2D` 注解声明 `"combo":"MASK"`，例如 `assets/effects/opacity/shaders/effects/opacity.frag` 的 `g_Texture1` 与 `assets/effects/blurprecise/shaders/effects/blur_precise_gaussian.frag:10` 的 `g_Texture2`。后者同一个槽位同时带 `"combo":"MASK"` 与 `"require":{"ENABLEMASK":1}`，把两类 combo 并列在一行里。
- 语料证据：52 个包、54 份去重 `scene.json`、2140 个 effect pass 中，`MASK` 被显式声明 **0 次**；同一批语料里 `[COMBO]` 块声明的 `ENABLEMASK` 出现 54 次、`BLENDMODE` 251 次。798 个 pass（37.3%）在 `textures` 数组的槽位 1 及之后绑了贴图。
- 结论：texture-slot combo（写在 sampler 注解里的 `"combo"`）不进 `scene.json`，由编辑器按该槽位是否绑图在编译期自动设置；只有 `[COMBO]` 块 combo 才会被写进 `scene.json`。因此「等 `combos["MASK"] == 1` 再启用遮罩」永远不成立，判据必须是槽位有没有绑图。
- 口径提醒：本页其他小节写的「1013 个 `scene.json`」是**文件级**口径——`.codex` 下 1013 份 scene.json 只来自 52 个包（同一包被多次 runtime-home 缓存），实例/pass 计数被按运行次数重复放大约 17 倍。跨小节比较数字前先确认口径。
- 边界：只证明 `MASK` 这一个 texture-slot combo 从不出现在语料里，并不证明所有 texture-slot combo 的默认值语义；也没有官方编辑器行为的直接抓取。

## 3. 使用规则

1. 专项表的 `L3` 行必须直接链接本页某个证据包，或自行给出代码、自动测试和运行证据三联。
2. 一个证据包只能证明标题和边界中写明的子集；不能横向给同名但未消费的官方能力升级。
3. 更新运行实现后先生成新的隔离报告，再更新本页、本专题表、总台账和现役计划。
4. 报告丢失、样本集变化或 App 身份变化时，保留历史数字但不得写成当前已复核事实。
