## 17. 刷新规则

每次刷新以 sitemap URL 集合为准，记录新增、删除和路径变化；不要按页面标题猜旧链接。若 `lib.sceneScript.d.ts` 的头部版本变化，单独比较 API 和事件差异，因为它不在 Scene sitemap 页面计数内。
