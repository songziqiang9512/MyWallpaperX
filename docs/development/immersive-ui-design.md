## 1. 本轮目标与确认边界

状态：2026-11-13，方案与效果图待用户确认。工作分支 `MWX/ui-immersive-redesign`。本轮允许研究、设计文档及生图，**用户认可效果图并同意执行前，不修改产品 UI 源码**。实施顺序只由[执行计划](immersive-ui-execution-plan.md)维护。

产品是原生 macOS 壁纸播放器：让用户在大幅作品中浏览、选择、了解并应用壁纸，管理本地内容、在线来源、下载与混合播放列表。新 UI 用 Swift + AppKit 独立实现；画布不是网页，不引入 Electron、WKWebView UI 或 SwiftUI。

本方案替代此前 Apple Music 式侧栏、常驻工具栏、统一方卡、卡内玻璃条及相关视觉目标。替换覆盖主窗口、全部来源页面、详情、搜索筛选、下载、列表组织、设置、属性、登录与附属面板；功能与用户数据由原服务继续承担。旧文档中的业务语义以[第 11 节](#capability-map)逐项接续，不能据此恢复旧 UI 设计。

交付的辨识点：**一面可双向漫游的作品墙；平时作品沉静，指针或选择落在哪里，哪里恢复原色与光。** 控制浮在作品上，窗口不再被固定侧栏与工具栏分割。

## 3. 视觉语言与尺寸

默认暗色作品墙，暖黑、烟紫玻璃、象牙白文字、少量柔玫瑰色。照片本身提供主要色彩。浅色沿同一几何和层级，以浅灰玻璃与深色文字替换；深/浅可跟随系统。效果图采用暗色和玫瑰色强调。

| Token | 设计值 | 用途 |
|---|---|---|
| Canvas | `#0C0B0E` | 卡缝、画布空白与预览底 |
| Surface | `#211D24` | 深色面板基色；玻璃合成后的颜色随背景变化 |
| Raised | `#363039` | 面板内按钮与选中胶囊 |
| Ink | `#F4F0EC` | 主文字、图标、聚焦描边 |
| Muted | `#ADA5AC` | 次级说明；禁用另降强度，不能用它表示失败 |
| Accent | `#E77991` | 主动作、小型活动指示、滑条有效段；错误另用系统语义色 |

字体使用系统字体。卡片标题 SF Pro Display / 苹方 20–28 pt semibold；界面正文 SF Pro Text / 苹方 13 pt；导航 13 pt medium；辅助文字 11–12 pt；数量、百分比和时长用等宽数字。标题最多两行，小卡一行；不把长文件名撑成大段文字。

基本间距 4 / 8 / 12 / 16 / 24 / 32 pt。画布卡缝默认 6 pt；卡角 4 pt，接近参考图的整面海报；面板角 26 pt、内块 14 pt，导航与底部控制为完整胶囊。仅浮层使用一层原生玻璃；卡片没有独立模糊、玻璃背板或发光动画。

保留主窗口最小 900 × 650 pt，设计基准 1440 × 900 pt，补验 1200 × 800 与原生全屏。窗口模式内容延至标题栏、背景经过交通灯下方；原生交通灯、系统窗角与安全拖动区保留。沉浸是内容占满窗口，进入原生全屏由用户决定，不在启动时强制占据 Space。

示意图中导航换行仅为文档排版；实际是一排融合胶囊。顶部中心距内容上缘 20 pt，高 44 pt，整排宽约 680–760 pt。最小窗口保留全部八项，缩小横向内边距，英文来源字号最低 12 pt；不横向滚动、不藏进 NSMenu。交通灯区与胶囊不重叠。胶囊下只有必要的短上下文，如“创意工坊 / 发现”，不再增加常驻页面标题带。

壁纸延伸到四边，被窗口自然裁切；不留大幅空白头区，不铺统计卡、欢迎标题或装饰侧栏。顶部文字可读性由局部渐暗承接。底部播放胶囊通常 460 × 64 pt，距底边 20 pt；工具按钮右下 56 × 56 pt，距边 24 pt。两者不共占空间；主窗口变窄时播放胶囊先收起次级说明。

## 5. 胶囊导航与自定义展开

“第一次 / 再次”按**是否已激活**判断，不做双击时间识别。点击非当前来源：直接进入该来源根列表，关闭原展开层；点击当前来源：展开其选择面板；再点当前来源：收起。切页只浏览，不改变正在播放的壁纸。进入子页后，父胶囊保持激活。

| 胶囊 | 第一次点击 | 当前胶囊再次点击后的内容 |
|---|---|---|
| 我的视频 | 本地视频墙 | 全部视频、视频中的喜爱/最近过滤、导入视频；不把下载 backing record 重复当本地项 |
| 我的图片 | 本地图片墙 | 全部图片、图片中的喜爱/最近过滤、导入图片 |
| 创意工坊 | 原发现根页 | 现有分类/订阅/作者浏览入口、账号状态、登录；保留来源实际支持的查询 |
| Wallhaven | Wallhaven 根浏览 | 分类、来源排序、比例/分辨率等已有筛选、API 设置 |
| Pixiv | Pixiv 排行根页 | 日/周/月榜、搜索/作者入口、插画/漫画、AI 与内容过滤、登录 |
| Pixabay | Pixabay 根浏览 | 视频/图片等现有查询、来源排序与筛选、API 设置 |
| 我的下载 | 各来源已发布内容的联合墙 | 全部、按来源/类型过滤、进行中任务与失败；本地历史不要求登录 |
| 播放列表 | 列表目录墙 | 特别喜爱、最近使用、自建列表、新建；列表内搜索及拖排列表顺序 |

展开为胶囊下方的 320–420 pt 宽圆角玻璃区，来源段与面板边缘有轻微连接感，无菜单箭头。采用原生 NSView/NSViewController 内嵌控件，不用 NSMenu 伪装。列表面板可搜索与滚动；操作项有图标、名称、必要说明，选中项有勾记。选择子页后关闭；筛选复选框保持展开并回显结果。账号表单由专门 sheet 承载。

同一时刻只有一个轻展开区：来源选择或工具面板/其子页。打开另一处替换前一处。点外部只关闭当前面板，本次点击不穿透去应用壁纸；Esc 收起并把焦点还给触发按钮。面板内滚动只滚面板，背后墙保持；开始在墙上平移时先关闭轻展开区。深详情与模态 sheet 另按其输入范围工作，不叠出多层可操作弹窗。

## 6. 二维画布、比例与排布

卡片宽高由缩略图经方向修正后的真实比例决定，`height = width / aspect`；大小随机体现为稳定的列宽变化，不拉伸图片、不把横图改成方卡。常用列宽约 220 / 300 / 400 / 520 pt，密度控制统一缩放这些宽度。相邻列避免同宽，各列内部从上至下紧排，列间的接缝错开；保留 6 pt 细缝。图片标题与操作浮在图内，不另加卡下信息区。

排布在数据快照、排序/筛选、密度或实际比例改变时准备。变化选择由稳定媒体 identity 与展示位置决定，不以系统随机数在滚动/重绑时重抽。外部尺寸只在原缩略图入口校正一次；缺比例时先用同来源已知比例或 16:10 占位，后台读到尺寸后一次修正受影响列，并保住当前浏览锚点。极长图保真实比例，不制造屏幕高到难以浏览的单卡：完整图在受限卡框中等比适配，空隙用该卡底色，详情可看全图。

默认可左右、上下及斜向连续漫游，鼠标滚轮纵向、Shift + 滚轮横向；触控板保系统方向、连续增量与惯性，不锁单轴、不吸附分页、不再次滤波。缩放以触点/当前焦点为锚点，密度变化不使选中的作品突然换到别处。普通左键用于选中和媒体拖动；空白处拖动或按住 Space 拖动用于平移，单独 Space 仍为预览。

无限画布是有限内容的空间延展，不等于凭空增加作品。足量本地内容采用一个稳定排布的周期副本；只有跨过本页内容范围后才重复，数量与关系始终按唯一媒体计。少于一屏的内容采用有界居中拼贴，不为铺满画面重复一两张。搜索/筛选结果为有界墙，结尾明确显示已显示数量，可回到未筛选墙；不会让三个命中项看似有无数结果。

在线墙的逻辑数据按原来源分页增长。可视需求接近未取数区域才提交下一页；二维副本不重复发网络请求。加载期间保留已就绪内容，边缘只留一个加载位置；无更多结果或失败时给出明确状态及重试。新页追加只补末端，不洗牌正在看的作品。返回页面恢复媒体锚点及相对位移；内容已删时使用原相邻逻辑项。

实现需要区分媒体 identity 与画布副本位置：喜爱、选择、下载和播放只指向原媒体；hover、命中与局部动画指向可见副本。删除一项撤掉它的所有副本，不产生重复关系或重复下载。页面排序定义逻辑媒体顺序，空间排列是其投影；键盘、播放与辅助功能仍可按该顺序完整到达内容。

## 7. 卡片状态与操作

| 状态 | 画面 | 操作与边界 |
|---|---|---|
| 静止未选中 | 原图上叠暖黑/烟紫约 42%，标题为安静的象牙色；无常驻按钮条 | 真实图片仍在，叠色不另生成一套图片 |
| 悬停 | 撤掉叠色，恢复原色原亮度，中心等比放大约 1.025；细内描边与轻投影 | 标题、类型/分辨率及“预览 / 设为壁纸”出现；放大只动呈现层，不改变其他卡布局 |
| 点击选中 | 离开鼠标后仍保持原色与轻微放大；单一细描边 | 单击不切换桌面；双击或明确“设为壁纸”才应用；单击偏好如选“打开详情”仍可保留 |
| 键盘焦点 | 清晰焦点环，原色，与选择采用相同尺度 | 方向键按空间邻近移动；移出视口时最短距离露出，不把焦点隐在浮层下 |
| 正在使用 | 小型活动标记及“正在使用”，不常驻跳动 | 仅播放状态不自动撤叠色或放大，遵守用户要求的 hover/选中聚焦范围 |
| 切换中 | 主动作变为“正在应用”，按钮内有活动指示 | 当前桌面继续沿原事务；迟到结果不改写新选择；失败局部显示“重试” |
| 未下载远端项 | hover 主动作“下载”；类型与分辨率仍可见 | 不伪装成可直接播放；下载中显示进度/取消，成功后沿原发布规则出现“设为壁纸” |
| 多选 | 小型勾选与焦点描边；只有当前焦点/hover 轻微放大 | 选择集合按媒体去重；不让全部选中卡同时弹起或自动播放预览 |
| 缺图/文件不可用 | 同尺寸中性占位、可读名称及具体状态 | 缺缩略图不等于壁纸不可播放；缺源文件才禁用相应动作，其他项照常可用 |

hover 进入 180–220 ms、退出 220 ms，叠色变化 220–260 ms。只对实际从旧状态变到新状态的可见卡做动画。滚动惯性中暂停逐卡悬停聚焦，停稳按真实指针恢复；点击、键盘、选择和拖放始终可用。动态缩略图沿已有 hover 预览能力，仅当前交互卡可播放，其他卡用静态图；不为整面墙启动播放器。

每张图底部仅有局部渐暗，保证标题对浅图也可读。图片/视频/Web/Scene 采用小型类型标识；分辨率、时长、文件大小以有意义的来源事实显示，未知不填虚构数字。右键保原生上下文菜单与相同命令；禁用原因在可见详情/提示中说明。

## 8. 单按钮工具面板

右下调节按钮展开约 360 pt 宽面板，向上生长，距按钮 12 pt；开合 200 ms，淡入并由 0.96 到 1，不使用夸张弹簧。按钮打开时转为关闭符号并保细强调环。面板内容超高时正文滚动，顶部动作与关闭仍在可见范围。

| 从上到下 | 内容与行为 |
|---|---|
| 六格快捷动作 | 导入、选择、下载管理、搜索、显示、设置；图标有 tooltip/AX 名称；按页面能力禁用，不把无效动作伪装成可用 |
| 页内搜索 | 点搜索或 `⌘F` 后在原面板中展开并聚焦搜索框；本地即时过滤，远端明确提交与加载，输入法组词不触发请求 |
| 音量 | 静音、滑条、百分比；消费现有全局音频状态，静态图片等无音频时说明当前不可调 |
| 当前页面 | 筛选摘要、排序摘要、卡片大小；点行在同一面板切入子页，顶部“返回”恢复；不层层叠 popover |
| 页面专属动作 | 本地导入类型；列表“编辑/复制/删除”；在线账号/API状态等，按当前页只投影有意义的项 |
| 墙面外观 | “原色聚焦”开关；开灯/关灯两段选择。开灯为柔和底层叠色，关灯加深未聚焦卡；同一外观模型投影到设置，不重设第二状态 |
| 底部 | 左侧灯光控制，右侧帮助按钮；帮助在原面板显示手势与快捷键 |

工具面板是旧工具栏动作的唯一常驻入口。导入、下载等常用动作另可从所属来源展开区与系统主菜单直达，使用同一命令，不复制执行逻辑。筛选子页用可读的分组标签、复选行/分段控件、清空筛选；我的下载保来源/类型/状态组内多选并集、组间交集。排序只有来源支持的项，最近使用固定成功时间顺序。密度只影响画布显示，不改播放顺序和媒体比例。

“显示”仅承接现有多屏支持开关、当前输出说明与填充方式，不增加尚未存在的逐屏独立壁纸能力。“透光”背后的音乐可视化没有直接对应的产品职责，本方案不启动第二个桌面预览引擎或透出用户其他窗口来模拟它。

<a id="focus-and-playback"></a>
## 9. 聚焦详情与底部播放胶囊

详情从选中卡片进入一个居中的聚焦面板，宽 920–1120 pt、高不超过窗口减 96 pt；左侧约 60% 为等比大预览，右侧为信息与动作。最小窗口改成上下结构，正文内部滚动，主动作固定在底部。背景墙轻暗化且不重排；关闭回到原卡与焦点。卡片已离屏时以淡出关闭，不飞向错误作品。

信息顺序：作品标题/作者 → 类型/分辨率/来源 → 喜爱与添加到列表 → 主动作 → 属性与文件/下载细节。视频用既有预览 owner；图片看完整原图；Web/Scene 默认用静态封面，参数编辑调用原属性会话，不为 UI 再启动一个引擎。远端 Pixiv 多页作品保页码与逐页下载/查看；Steam 订阅与本地喜爱用不同图标和文案。作者、来源与文件入口不藏在无说明的图标里。

视频填充、速率、循环和音频；Web/Scene 的现有作者属性；静态图片的已有适配动作均在相应详情里出现。参数编辑采用同一玻璃表单与实时回显，但提交、持久化、取消和恢复默认仍归原 owner。UI 不把未完成请求称为已应用，也不删除作者当前不支持的参数来掩盖失败。

底部胶囊显示**真实正在使用的内容**，不随浏览选择跳标题。内容为小封面、名称/类型、上/下张、可用时的播放/暂停、显示摘要。点封面/标题定位或打开当前壁纸详情；播放策略与顺序从当前播放来源取值，浏览其他页不改变它。Video 可在展开详情中显示真实时长/进度；图片、Web、Scene 不放假的歌曲进度条。没有播放内容时胶囊收起；暂停/系统策略暂停和切换失败各有清楚文字。

多选时在底部原位显示“已选 n 项”与喜爱、加列表、移除/删除、完成，临时接替播放控制的可见位置；后台播放状态不变。在线原本没有批量下载能力的页面不新增假批量按钮。删除关系与删除源文件始终是两个有名字的动作；源文件删除沿原确认与废纸篓语义。

<a id="secondary-surfaces"></a>
## 10. 播放列表、下载及附属界面

列表目录也是作品墙：一张成员封面为主体，标题与成员数在图内，目录标识清楚；空列表使用有比例的中性图面，不伪造封面。新建入口放在胶囊展开区与空态主按钮，避免把“＋”当成壁纸随机散落。进入列表后短上下文含“返回所有播放列表 / 名称 / 数量”，播放、随机、添加从上下文与工具面板直达。新建/编辑 sheet 有名称、封面和成员选择，保存后关闭；复制/重命名/删除沿原 UUID 与关系语义。

媒体拖动到“播放列表”胶囊：短停后展开接受区，再落到目标列表；不会顺便切播放来源。目录列表顺序在展开区拖排，墙上成员默认不拖动改序。向窗口拖入文件显示轻量导入落点，具体入库仍由原导入 owner 执行；远端卡不是本地文件，不假装支持 Finder 导出。

下载管理在工具面板内切到任务页；每行封面、来源、名称、进度/大小、暂停/取消/重试与具体失败。长列表独立滚动，成功内容通过“我的下载”看；历史与当前会话分区，注销不清空本机记录。下载完成只更新事实，不突然跳页或覆盖新用户播放意图。

设置使用新的 AppKit 设置窗口，顶部六项分段导航“播放 / 显示 / 节能 / 系统 / 快捷键 / 维护”，统一玻璃底、行高 44 pt、内距 20 pt、明确的说明与表单标签。页面布局重写，绑定到现有设置权威；不保旧侧栏与旧设置块外形。长页只滚正文，修改按原保存语义即时生效，需提交的文本明确“保存”。`⌘,` 始终可达。

登录/API、导入进度、列表选择/编辑、清理/重置确认、Scene/Web 属性、屏保配置、关于/更新/帮助入口全部用相同字阶、圆角、间距和按钮层级重设计。登录表单不任意拖移；异步反馈在本表单显示，账号切换时原请求身份由服务决定。系统文件/颜色选择器、系统授权与普通 NSAlert 保留系统行为。屏保页面如实区分已有自动屏保与尚未实现的即时主动锁屏。

菜单栏状态面板同步新封面/播放控件/信息层次，监控信息仍消费原 owner，不给它另造计时器或另一份播放状态；关闭主窗口后播放与状态栏仍可用。原菜单、快捷键、帮助与更新的命令重绑新入口，主菜单保原生 macOS 菜单行为。

## 12. 空态、失败、键盘与辅助功能

无本地内容：画布中心一个克制的导入块，“拖入视频或图片”与“导入…”；胶囊与在线来源可达。不展示虚构作品。加载：先保卡几何，静态占位淡入；初始未知不写“0 张”。无搜索结果：说明当前条件，提供“清空筛选”。离线/登录过期：保已显示和本地内容，在对应来源上下文给重试/登录，不全窗锁住。操作失败只影响对应卡/表单/任务；不因一个坏缩略图阻止整页浏览。

键盘：Tab 按“导航 → 内容 → 底条 → 工具”循环；方向键在墙上空间移动；Space 预览，Return 应用可播放选中项或进入列表；`⌘F` 搜索，`⌘I` 详情，`⌘A` 当前可组织范围全选，`⌘+/-` 卡片大小，`⌘Z/⇧⌘Z` 撤销重做，`⌘,` 设置。最终快捷键与现役主菜单核对后只保一份绑定；文本编辑/输入法组词时先交原生 field editor，Space 拖移不抢文字输入。

Esc 优先关闭最上层临时面：sheet 按其取消语义、详情、展开区、多选；无临时面时不停止壁纸。弹层关闭后恢复触发焦点。VoiceOver 按逻辑唯一内容读名称、类型、可用状态与主动作，画布重复副本不重复播报；hover 控件均有等价键盘/AX 动作。减少动态效果时去缩放与飞入，用短淡化/即时更新；减少透明度时面板实色；提高对比度时加强文字/描边，不能靠玫瑰色单独表达状态。

## 13. AppKit 落地边界与成本

```text
原 Catalog / 来源查询 / 关系 Store / 播放事实
  → WallpaperLibraryPresentation（唯一路由、查询、选择）
  → App 层装配（将来源值和现有命令接入新 Shell）
  → 沉浸 Shell（导航 / 画布 / 一个轻展开区 / 详情 / 底条）
  → 原 Commands / 来源动作 / Manager → 原播放事务与进程
```

在原 `WallpaperLibraryWindowComposition` 内替换 Shell 装配；保 `Workspace/Presentation` 的产品职责。新 Shell 根控制器替代 `AppKitMainSplitViewController` 的主窗装配角色；旧类无其他消费者后删除。画布只新增一个必要的几何布局类型：原 `WallpaperLibraryGridController` 承接集合/选择/复用，`NSCollectionViewLayout` 子类消费比例与几何值，不持来源服务。统一壁纸 cell 替代按来源重复的 UI 卡片，来源 adapter 只交显示值、缩略图需求和命令；远端仍保原查询与分页 owner。

无限浏览采用有界的可见副本窗口与坐标重定位，原 NSScrollView/NSClipView 承接两轴相位及惯性；重定位同次抵消内容偏移，不能重启手势。有限 `IndexPath` 映射可见副本到媒体，不伪造无限 item 总数。实现前先完成执行计划中的原生几何切片，实测重定位、缩放和输入连续性；它是本设计最大的技术风险，失败则修订此实现方案，不悄悄交付为单向瀑布流。

布局只在真实失效边界准备列和高度索引；平移查询视口与有界邻域，不逐帧扫描全库、解码、哈希、重建查询或发整页快照。缩略图仍走[现有交付合同](thumbnail-delivery-design.md)，按二维目标像素请求，不因为大卡放大而常驻原图；不增加缓存预算。副本共享原媒体缩略图 producer，撤掉视口只撤本 consumer。动画用 Core Animation；静止时无墙面 display link/Timer，菜单栏监控也不新增轮询。

原生依据：[NSCollectionViewLayout](https://developer.apple.com/documentation/appkit/nscollectionviewlayout) 支持自定义几何与局部失效；[NSEvent.momentumPhase](https://developer.apple.com/documentation/appkit/nsevent/momentumphase) 提供滚动惯性相位；[NSVisualEffectView](https://developer.apple.com/documentation/appkit/nsvisualeffectview) 承接有限控制面的材质。以上只支撑 API 选择，不证明无限画布的手感、性能或本项目接线已经通过。

UI 的新状态仅包含面板呈现、密度、外观和画布锚点；不重建认证、下载、播放、时钟、资源或输出权威。旧纯 UI 偏好在原解码/设置入口映射或弃用为默认值，不新增迁移服务；有效用户媒体、数据库、列表和播放设置不重置。每阶段替换后同时删旧视图、动作投影与失效测试，不保长期“经典界面”分支，不在新 Shell 外再留一套活的旧窗口。

## 14. 效果图与设计验收

计划提供四张同一语言的生图：A 主墙与 hover；B 单按钮展开的完整工具面板；C 播放列表胶囊展开；D 聚焦详情。它们是视觉提案，不是实际 App 截图；中文细小字、像素尺寸、透明材质与动效最终以本规范及实际 AppKit 验收为准。提示词和最终候选保存在本机忽略产物目录，见执行计划的交付记录。

先审以下决定：满幅二维海报墙是否足够接近参考；真实比例与稳定随机大小是否成立；只有悬停/选择明亮突出的层次是否正确；一体胶囊与“再点展开”是否符合预期；玻璃面板与底条是否克制；详情及附属界面是否同一语言。用户确认后修订本规范及设计登记再开始实施，调整仍在同一文档，不建立第二套规范。

未验证边界：生图不能验证无限平移、复用/内存、原生材质、辅助功能、在线账号、真实下载、跨引擎播放或多屏。完整验收、旧 UI 删除和可交付停止条件由执行计划逐项规定。
