# MyWallpaperX 2.12.0

把本地媒体、已下载壁纸和在线图片放进更统一的原生资料库；菜单栏也能直接查看和控制当前壁纸。Scene 方面扩展了部分作品的动画、视频纹理、粒子与脚本交互。以下为相对正式版 2.11.0（2026-10-19）的变化。

**使用要求：macOS 26.0 或更新版本、Apple Silicon。Scene 仍在持续扩展兼容范围。**

## 新增

<details>
<summary>展开新增功能</summary>

- **统一资料库与播放列表**：在原生主窗口浏览本地视频、已下载壁纸和图片；创建播放列表、整理内容，并在支持的页面导入、收藏、搜索和预览。
- **Wallhaven 与 Pixiv 在线浏览**：搜索和筛选图片，预览后下载或应用。Wallhaven 可填写 API Key 并查看账号可访问的收藏集；Pixiv 使用用户自己的登录会话。
- **菜单栏壁纸控制面板**：查看当前壁纸、封面和播放状态，控制暂停、音量、上一张／下一张与轮换方式，也可打开设置和壁纸属性。
- **Scene 脚本交互扩展**：补充向量反射等脚本计算能力；兼容作品可在鼠标交互后打开用户选定的快捷方式。
- **Scene 粒子与光照扩展**：支持更多 Sprite 粒子边缘覆盖效果，让已支持的特效能够响应场景光照。

</details>

## 修改

<details>
<summary>展开行为变化</summary>

- **资料库采用统一的原生页面**：侧栏集中显示不同内容来源，卡片、工具栏和详情操作随页面变化。本地图片与视频可用系统 Quick Look；Web 和 Scene 继续使用各自的详情或预览方式。
- **在线图片详情操作调整**：Wallhaven 与 Pixiv 详情页提供下载／应用和打开原网页入口；下载内容加入对应资料库。已有媒体保留原位置并继续按兼容规则读取。
- **状态栏面板重新设计**：常用播放控制、当前封面和壁纸信息集中在菜单栏弹出面板中；打开设置或属性时进入对应窗口。
- **Scene 模型动画控制**：扩展已支持直接模型的作者动画属性和播放速率控制，改善骨骼姿势与动画数据的衔接。

</details>

## 优化

<details>
<summary>展开优化内容</summary>

- 调整资料库网格、缩略图和预览调度，减少滚动、悬停和列表刷新时的重复工作，让可见内容优先获得缩略图。
- 精简 Scene 与 Web 的准备和帧处理工作，并复用可复用的分析和资源结果。
- 视频索引保存按序处理；退出时跳过已经完成的重复写入。
- 减少常用播放切换、资源和资料库操作中的冗余步骤，改善浏览与切换响应。实际体验会因内容和设备而异。

</details>

## 修复

<details>
<summary>展开问题修复</summary>

- **资料库与浏览器**：改善预览、设置窗口、菜单和列表更新时的状态衔接，修复快速切换页面、恢复浏览位置及下载失败反馈中的问题。
- **Scene 画面与脚本**：修正部分材质颜色、图层合成和脚本输入处理；修复某些 Puppet 作品重复拖动后不再响应，以及文字在显示状态切换时丢失的问题。
- **Scene 视频纹理**：修正部分作品内嵌视频的首次呈现、播放跳转和后续画面更新，避免把定位前的旧画面当作新帧。
- **视频与 Web**：修复视频索引退出保存处理，并减少 Web 准备阶段重复处理输入和媒体的问题。

</details>

## 已知问题

<details>
<summary>展开已知问题与适用限制</summary>

- Scene 尚未覆盖 Wallpaper Engine 的全部脚本、材质、模型动画、粒子和复杂组合；未支持的内容可能缺失或与原作不同。模型动画、视频纹理及粒子等新能力也仅适用于已支持的格式和条件。
- 在线图片浏览受服务状态、网络、账号登录、作品权限和来源 API 限制。Pixiv 需要用户自行登录；Wallhaven 收藏集需要有效 API Key 和相应账号权限。
- Web 壁纸依赖 WebKit、作品自身资源和系统窗口调度；远程资源不可用或切换桌面空间时，页面可能无法完整显示或短暂停顿。

</details>
