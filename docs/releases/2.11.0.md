# MyWallpaperX 2.11.0

本次更新继续完善原生壁纸体验：Web 壁纸改由独立播放进程承载，Video／Web／Scene 切换更可靠；Web 与 Scene 共用歌曲信息，并扩展 Scene 的属性热更新、动画与材质支持。以下为相对上一正式版本 2.10.1 的变化。

**使用要求：macOS 26.0 或更新版本、Apple Silicon。Scene 兼容性仍在持续完善，复杂作品可能存在显示差异或性能问题。**

## 新增

<details>
<summary>展开：歌曲信息、Scene 动画与交互能力</summary>

- **Web 壁纸歌曲信息**：支持相关接口的网页作品可显示系统当前歌曲、歌手、封面和播放进度，与 Scene 共用设置中的「壁纸歌曲信息」开关及媒体来源；关闭后清空作品收到的信息。
- **Scene 动态内容扩展**：支持范围内的脚本可创建拥有独立状态的文字及 Puppet 实例，更新文字字号、图像亮度、背景颜色和 Bloom 强度，并控制声音音量、播放与随机音源。
- **Scene 动画支持扩展**：接通更多命名 Timeline、组合动画、相机开场动画及 Puppet 动画事件；为经验证格式的直接模型接入骨骼动画，保留作者模型的空间坐标与材质表现。
- **更多文件属性**：支持范围内的 Scene 文件属性可在播放中切换图像或视频纹理；资源无法解码时保留可用内容，并在面板中显示相应状态。

</details>

## 修改

<details>
<summary>展开：播放切换、属性面板与开源声明</summary>

- **Web 改为独立播放进程**：网页、输入与资源服务在后台播放进程运行，减少主界面忙碌对网页播放的影响；作品准备与宿主初始化可以并行进行。
- **统一三类壁纸的切换交接**：新作品准备并确认可显示后再交接桌面；取消、启动失败和迟到的旧请求按同一切换事务处理，改善连续切换和失败回退。
- **统一 Web / Scene 属性面板**：调整分组、标签、控件和状态提示的呈现，完善作者属性名称的本地化与换行，改善较长说明和稀疏属性布局。
- **完善工坊管理**：统一作品详情与作者页导航，按稳定的本地统计排序已下载作品，并改进批量删除后的列表和选择状态。
- **明确开源许可**：项目自有代码采用 GNU GPL 3.0，补齐根目录 LICENSE、项目与第三方声明，以及发行包内的许可材料。

</details>

## 优化

<details>
<summary>展开：加载准备、资源复用与日常响应</summary>

- 复用 Scene 已准备的材质、纹理、图层与属性条件，减少属性编辑期间重复解析、构建与整场景重启；能够直接更新的属性沿现有播放会话生效。
- 复用已验证的包解压、纹理解析、shader 分析和编译结果，限制已完成缓存的保留量，并修正源码变化后的旧缓存失效处理。
- 减少 Scene 逐帧重复的纹理快照、资源驻留和材质准备工作，在适用路径保留原生压缩纹理；不对所有作品作统一性能提升承诺。
- 优化本地库、工坊网格、缩略图和详情预览的请求调度与复用，减少列表更新及下载进度刷新引发的重复工作。
- 正式 Release 裁去开发期诊断与部分调试采集，保留必要错误信息；完善发布检查、回归测试选择及开发文档导航。

</details>

## 修复

<details>
<summary>展开：播放、Web、Scene 与工坊问题</summary>

- **播放与音频**：修复跨引擎交接中的旧请求覆盖、资源访问授权衔接和频谱投递问题；调整共享音频频谱的动态范围，改善兼容作品的音频响应。
- **Web 稳定性**：修复空目录监听可能触发大范围扫描、导致页面高占用和动画停滞的问题；完善资源授权、暂停恢复、导航及子页面通信，保留作品自行暂停的媒体状态。
- **属性编辑**：修复快速连续编辑时属性丢失、延迟启动事件覆盖新值、部分颜色与布尔设置未正确生效，以及拖动控件或恢复默认值时的状态衔接问题。
- **Scene 合成与颜色**：修正透明度、原始颜色、数据纹理、局部特效失败及组合图层边界的传递，改善透视背景、叠加发光与材质纹理细节。
- **Scene 模型与动画**：修正模型深度、相机坐标、蒙皮姿态、Puppet 裁剪、动画曲线和回调顺序，以及部分光照、高光与阴影问题。
- **Scene 粒子与脚本**：修正世界空间粒子、拖尾／绳索及相机继承问题，完善作者 shader 的类型转换、作用域和宏处理；单个可降级输入失败时尽量保留其他有效内容。
- **界面与工坊**：修复工坊缩略图状态、详情缓存、作者页返回来源、列表恢复、网格缩放和批量移除时的状态同步问题。

</details>

## 已知问题

<details>
<summary>展开：兼容性、系统媒体及运行边界</summary>

- **Scene 尚未完整兼容 Wallpaper Engine。** 部分复杂特效、脚本、模型动画、粒子和交互仍可能缺失或与原作有差异；直接模型动画目前只支持经验证的格式与动画条件，不能据此推定全部模型兼容。
- 复杂作品的 CPU、GPU、内存和能耗仍有优化空间；局部修复和代表样本通过不等于所有作品均流畅或长时间稳定运行。
- Web 作品仍受 WebKit 与窗口系统调度影响，切换桌面空间时部分作品可能出现短暂停顿；依赖远程服务或其他作品的内容仍需要可用网络与完整资源。
- 歌曲信息取决于播放器提供的系统媒体数据、作品支持及相应权限，尚未覆盖所有播放器、歌词与全部封面表现。
- Steam 登录与下载受服务状态、账号访问权限及网络环境影响。本次更新不绕过平台或作品授权。

</details>
