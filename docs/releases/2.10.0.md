# MyWallpaperX 2.10.0

这是一次跨越多个开发阶段的大版本更新，主要围绕界面与日常操作、Steam 创意工坊体验，以及 Scene 场景壁纸引擎展开。创意工坊从 SteamCMD 迁移至 SteamKit；Scene 从早期支持推进到基本可用阶段，并将继续完善兼容性与性能。

## 新增

- 应用内 Steam 登录面板，支持扫码、账号密码登录及 Steam Guard 验证，可记住登录状态并切换账号。
- 独立的下载任务面板，集中查看任务进度、排队和失败状态，并可直接重试失败的下载。
- 全新中英文帮助文档，覆盖 Video、Web、Scene 的使用方式、工具栏、快捷键、工坊 ID 搜索，以及登录和下载问题排查。

## 修改

- **界面与操作调整**：重新整理工具栏弹出面板、壁纸卡片、详情和下载列表，统一视觉样式与常用操作入口，让浏览、管理和播放壁纸的流程更连贯。
- **弃用 SteamCMD，全面迁移至 SteamKit**：重整登录、浏览、查询与下载流程，整合「我的订阅」「我的收藏」查看及订阅管理，完善个人列表加载和账号状态同步。
- **Scene 引擎大幅完善**：扩展图层与材质、特效与后处理、粒子、动态文字、脚本，以及鼠标和音频响应等能力；支持调节作品开放的属性，支持范围内的场景壁纸已可用于日常播放。
- **统一三种壁纸的播放控制**：Video、Web、Scene 共用音量、静音、暂停和继续播放控制；焦点、全屏、电源与电脑不活跃等暂停策略统一作用于三种引擎。

## 优化

- 完善工坊登录状态恢复、下载重试、任务取消与错误提示，减少浏览、登录和下载之间的操作中断。
- 整理本地工坊文件管理：下载目录使用清晰的作品 ID，列表与实际文件同步；删除已下载壁纸时同步删除本地内容，清除任务历史则保留正在进行的下载。
- 优化 Scene 的加载、资源准备与运行流程，减少播放期间的重复工作；精简应用内置资源，仅保留两段压缩后的演示视频，减小包体积。

## 修复

- 修复工坊下载授权与会话衔接、作者工坊跳转，以及本地文件缺失后仍显示空条目等问题。
- 修正 Scene 中多处图层变换、粒子、文字、颜色合成与鼠标交互问题，并改善三种壁纸切换、暂停和恢复时的状态衔接。

## 已知问题

- **Scene 已基本可用，但尚未完整兼容 Wallpaper Engine 的全部效果。** 部分复杂材质、特效、脚本、粒子和交互可能显示不完整或存在差异，复杂场景的性能也仍有优化空间。后续将持续完善兼容性、播放效果与运行效率。
- Steam 登录和下载仍受服务状态、账号权限及网络环境影响；部分 Web 壁纸依赖远程服务或其他作品，离线或缺少依赖时可能无法正常显示。相关排查方法已收录在帮助文档中。
