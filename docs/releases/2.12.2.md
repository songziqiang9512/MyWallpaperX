# MyWallpaperX 2.12.2

现在主程序的操作和界面整体流畅度得到了显著提升，更加顺滑了。
对Scene的架构进行了一些调整，扩展Scene壁纸的粒子、骨骼动画与组合结构支持，改善资料库滚动和详情操作，并修复 Web 与屏保的若干问题。
以下为相对正式版 2.12.1的变化。

**使用要求：macOS 26.0 或更新版本、Apple Silicon。Scene 仍在持续扩展兼容范围。**

## 新增

<details>
<summary>展开新增功能</summary>

- **Scene 粒子**：支持静态球体碰撞、事件尺寸与透明度继承、按周期限制发射数量，以及控制点粒子组件；已支持的粒子作品动作更完整。
- **Scene 骨骼与组合结构**：恢复旧版 Puppet 作品的骨骼动画与绑定网格；分层组合的子物体按作者结构一起显示，命名源与效果可以正确衔接。
- **Scene 材质与文字**：补充只读折射深度、视频材质和离屏效果下的文字颜色，部分作品的画面缺失或偏色得到修复。

</details>

## 修改

<details>
<summary>展开行为变化</summary>

- **屏保改用系统原生视频扩展**：由系统在 App 完全退出后独立播放。使用屏保的用户升级后需在“系统设置 → 屏幕保护程序 → 自定义 → MyWallpaperX”重新选择视频；原生扩展只出现在屏保分组，不再出现在墙纸列表。
- **统一界面控件**：玻璃弹窗动作、详情菜单、卡片描边与选中标记、空状态使用一致的样式。
- **启动先显示本地内容**：打开 App 先展示上次的本地记录，目录检查在后台完成后再更新列表。

</details>

## 优化

<details>
<summary>展开优化内容</summary>

- **缩略图复用**：网格、详情、选择器和下载行共用同一份取图结果，滚动回访和窗口缩放时减少重复解码与空卡。
- **资料库响应**：批量准备来源与列表数据，减少页面切换、搜索和筛选中的重复扫描与投影。
- **Scene 启动**：首次粒子预热移到主线程之外，打开或切换作品时主界面更少阻塞。
- **网络与媒体准备**：合并 Web 请求准备、随机目录刷新和滑块预览提交中的重复工作，视频缩略图优先交付已生成结果。
- **架构调整**：合并重复的渲染与资料库实现，删除废弃路径，降低常驻工作与维护成本。

</details>

## 修复

<details>
<summary>展开问题修复</summary>

- **Scene**：修复粒子随父物体移动时错位、父物体销毁后子物体残留、Rope 图集缺图、文字在 HDR 关闭或离屏效果后偏色，以及部分着色器全局、控件点与命名效果不生效的问题。
- **Web**：正确处理 XHR 中止、当前请求周期内的回包和已取消的 fetch，避免旧画面覆盖新提交；修正主音量与静音控制。
- **下载与播放列表**：多个下载失败提示依次显示，重复进度更新时保持速度稳定；播放列表按实际加入时间排序。
- **资料库与详情**：修复视频缩略图迟到时不显示、详情重载后错误提示残留、筛选后多选未清除，以及选择状态与卡片操作不同步。
- **设置与屏保**：保存前统一热键冲突，关闭文件选择器后再显示结果；屏保清理失败时保留原始错误。

</details>

## 已知问题

<details>
<summary>展开已知问题与适用限制</summary>

- 主动锁屏时需要等系统闲置屏保计时到达后才开始播放视频；
- 屏保只支持本地视频，Web 与 Scene 不提供屏保来源；
- 部分复杂 Scene 作品仍可能缺少特效、动画或交互，与原作存在差异。
- 在线图片浏览受服务状态、账号权限和网络影响；Web 壁纸依赖 WebKit 与作品自身资源，远程资源不可用时可能显示不全。

</details>
