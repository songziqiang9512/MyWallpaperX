# MyWallpaperX 2.10.1

这是一次围绕日常体验与播放稳定性的更新，完善设置、壁纸切换和 Steam 创意工坊下载管理，并修复 Web 与 Scene 壁纸在加载、交互和显示中的多处问题。Scene 继续扩展支持范围，复杂作品的兼容性与性能仍将持续完善。

## 新增

- 设置中的「启动恢复播放」开关，可恢复上次使用的视频、Web 或 Scene 壁纸，并保留退出前的暂停状态；关闭后启动应用不自动播放。
- 下载任务面板新增暂停、继续、优先下载和「重试全部失败」，暂停时保留已下载内容，方便安排下载队列。
- 「Scene HDR 显示」开关，在支持的屏幕上呈现更亮的高光，可在播放中切换为普通亮度（需要壁纸自身支持）。
- 「壁纸歌曲信息」开关，让支持该功能的 Scene 作品显示正在播放的歌曲与封面；默认关闭，读取 Apple Music 时可点击「授权读取」。

## 修改

- **统一壁纸切换范围**：全局快捷键、状态栏和菜单中的上一张／下一张加入已安装的 Web、Scene 壁纸，自动跳过缺少依赖或无法播放的项目。
- **完善壁纸详情操作**：正在播放的视频卡片和详情按钮可直接停止播放；图片详情新增「设为壁纸」，工坊详情精简操作并显示本地作品的实际文件大小。
- **扩展 Scene 支持范围**：完善组合图层、静态模型材质与光照阴影、Puppet 骨骼动画及部件裁剪，并支持部分内嵌 VP9 WebM 视频。
- 改善 Web 高兼容模式的页面数据隔离。更新后，部分作品自行保存的页面状态可能需要重新设置；应用中的作品属性仍由原设置入口管理。

## 优化

- 优化视频、图片、在线库和工坊列表的缩略图加载与缓存，减少滚动、详情预览和下载进度刷新时的重复工作；工坊动态缩略图默认显示静态帧，悬停时才播放动画。
- 将大文件夹图片导入、已下载工坊库扫描，以及 Web 启动时的项目解析和缓存处理移至后台，减少这些操作对界面响应的影响。
- 改善 Scene 的启动准备与缓存复用，批量处理纹理上传相关工作，并及时释放已完成准备的解码缓存。

## 修复

- 修复设置窗口整体偏左、左右留白不一致的问题，滚动后保持正确布局。
- 修复设置修改未正确保存或投递、静音显示不同步、多显示器与填充模式衔接，以及旧设置缺少字段时恢复失败等问题；「同步系统壁纸」现在也可从 Web、Scene 截取画面，并在每次切换时更新。
- 修复视频详情缩略图补齐后不刷新、空库导入后自动切换未恢复、标签内方向键选择越界、快速开关详情面板错位，以及编辑文字时快捷键误切壁纸等问题。
- 修复 Web 连续点击时旧启动请求覆盖新选择、部分子页面请求收不到回包、本地特殊文件名解析错误和远程字体加载问题；改善暂停与恢复，保留作品自行暂停的媒体和动画。
- 修正 Scene 中多处颜色与透明度合成、HDR 与 Bloom、模型灯光和阴影、文字对齐与换行、粒子拖尾和透明度问题，改善脚本显隐、属性热更新及暂停后文字、封面更新的显示衔接。
- 修复工坊下载失败提示遗漏、已下载列表与本地文件状态不同步、Steam Guard 重试保留旧验证码，以及属性滑块操作被界面重建打断等问题。

## 已知问题

- **Scene 尚未完整兼容 Wallpaper Engine 的全部效果。** 部分复杂材质、特效、脚本、粒子、模型和交互可能显示不完整或存在差异，复杂场景的性能也仍有优化空间。
- 歌曲信息取决于播放器是否提供可用的系统媒体数据及相应权限；尚未覆盖所有播放器、歌词与全部封面表现。
- Steam 登录和下载仍受服务状态、账号权限及网络环境影响；部分 Web 壁纸依赖远程服务或其他作品，离线或缺少依赖时可能无法正常显示。
